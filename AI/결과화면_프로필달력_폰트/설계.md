# 결과 화면·프로필 달력·폰트 설계

## 폰트

- 사용자 지정 폰트: PF 스타더스트 3.0 Bold.
- 원본: `C:/Users/eeseo/AppData/Local/Microsoft/Windows/Fonts/PF스타더스트 3.0 Bold.ttf`.
- 프로젝트 리소스: `Assets/Resources/Fonts/PFStardustBold.ttf`.
- 동적 UI: `UiKit.Font`가 프로젝트 리소스를 읽음.
- 편집기 작성 코드: 공통 `UiKit.FontAssetPath` 사용함.
- 기존 씬·프리팹·ScriptableObject의 Font 참조도 교체함. 생성 코드만 바꾸고 기존 참조를 남기지 않음.
- 글자 내용·크기·배치·스타일은 폰트 이전 작업에서 별도로 변경하지 않음.
- 테스트·복구 자료와 패키지·Library·Aseprite/FBX 생성 에셋은 폰트 이전 대상에서 제외함.

## 결과 프로필

- 최종 모집 인원 6명의 프로필을 오른쪽 상단에 배치함. 이름·파트 및 허위 포트폴리오 표시도 제공함.
- 공통 화면의 기존 `Profile` 오브젝트 계층을 복제하여 전용 프리팹으로 재사용함.
- 원본 경로: `InterviewScreen/InterviewAuthoredUi/DiscordViewRoot/CallChannelAnchor/CallParticipants/SlotGroup0/Profile`.
- 배경 Image·마스크 Image·Portrait Image를 분리한 기존 스텐실 구조 유지함.
- 시각 리소스는 `ApplicantVisualCatalog`에서 CharacterId로 조회함.

## 달력

- 개발 1~30일을 7열·5행으로 표시함. 실제 월·연도는 데이터에 없으므로 특정 달의 날짜로 해석하지 않음.
- 달력 전체 배경과 각 날짜 칸 배경을 Image로 작성함.
- 각 날짜의 작업일 여부는 `ScheduleResult.ProjectSchedule`을 사용함.
- 멤버의 불가일이면 해당 칸에 프로필을 표시함.
- 불가일이 작업일과 겹침: 빨강 상태 표시.
- 불가일이 작업일이 아님: 초록 상태 표시.
- 프로필 수가 늘어나면 각 칸 GridLayoutGroup의 셀 크기를 사용 가능한 영역에 맞춰 축소함.
- 런타임에 UI를 매번 생성하지 않고 편집기에서 날짜·프로필 슬롯을 작성함.

## 결과 데이터

- 현재 팀 캡처 → 결과 투영의 기존 분리 구조를 사용함.
- 결과 멤버에 CharacterId와 복사된 불가 일정을 전달하여 이름이나 화면 순서로 프로필을 추측하지 않음.
- 기존 생성자 호출과 호환되도록 확장함. 정확도·별점·엔딩 판정 산식은 변경하지 않음.

## 정확도·버튼

- 전체 정확도: 노란 Image, 가로 채움 100%.
- 현재 정확도: 위에 겹친 빨간 Image, `AccuracyPercent / 100`으로 가로 Fill.
- 현재 표시 정확도는 기존 floor 처리된 결과 값을 사용함.
- 디버그 합계·정확도 정보는 프로필/달력과 겹치지 않는 구역에 배치함.
- 결과 진행 버튼과 엔딩의 메인 버튼은 오른쪽 아래에 배치함.

## 에셋 적용

- 공통 ResultBoard 프리팹 및 기본·Good·Normal·Bad 결과 씬을 각각 갱신함.
- 기존 씬을 다른 결과 씬 복사본으로 덮지 않음. 각 씬의 테마·기타 루트 보존함.
- 변경 전 디스크 및 열린 씬의 미저장 상태를 백업함.
- 전역 SaveAssets/SaveOpenScenes 대신 변경 대상만 저장함.
- Play 검증·테스트·커밋은 이번 요청에 포함되어 있지 않음.
