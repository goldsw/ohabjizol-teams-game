# 적용 결과

## 적용 완료

- PF 스타더스트 3.0 Bold를 프로젝트 Resources에 복사하고 동적 UI·편집기 작성 코드의 기본 폰트로 연결함.
- 기존 프리팹 18개·씬 6개의 Font 참조 378개를 추가 교체함. 결과 UI 작성 중 교체된 폰트는 이 집계에서 제외됨.
- 모집 인원 6명의 사진·이름·파트를 오른쪽 상단에 배치함. 허위 포트폴리오 표시도 유지함.
- 기존 Profile 오브젝트를 [전용 템플릿](../../Assets/Prefabs/InterviewRefresh/ResultProfileTemplate.prefab)으로 추출하여 같은 배경·스텐실·Portrait 계층 사용함.
- 달력: 개발 1~30일, 7열·5행, 빈칸 5개 포함. 전체 배경 및 날짜 칸 배경 Image 작성함.
- 각 날짜 칸에는 최대 6명 프로필 슬롯을 미리 작성함. 쉬는 지원자의 프로필만 표시하며 작업일이면 빨강, 비작업일이면 초록 배경으로 표시함.
- 칸별 GridLayoutGroup과 ResultResponsiveGrid가 크기를 계산하여 프로필을 축소 배치함.
- 노란 전체 정확도 바 위에 빨간 현재 정확도 Fill을 겹침. 기존 표시 정확도 값을 사용함.
- 결과 진행 버튼 및 엔딩의 메인 버튼을 오른쪽 아래로 이동함.
- 공통 결과 프리팹, 기본·Good·Normal·Bad 결과 씬, 기존 엔딩 씬들에 저장함.

## 편집 위치

- [ResultBoard 프리팹](../../Assets/Prefabs/InterviewRefresh/ResultBoard.prefab)
  - `AuthoredUi/SelectedRoster`: 모집한 지원자 사진·이름·직군.
  - `AuthoredUi/ResultCalendar`: 달력 전체 배경.
  - `ResultCalendar/CalendarGrid/Day01` ~ `Day30`: 칸 배경, 날짜, 작업일 표시.
  - 각 칸의 `OffdayProfiles`: 프로필 배치 그룹.
  - `AuthoredUi/Accuracy`: 노란 전체 바. `CurrentRed`: 빨간 현재 Fill.
  - `AuthoredUi/ContinueButton`: 진행/메인 버튼.
- 사진 형태 수정은 템플릿의 `ProfileBackground`, `ProfileMask`, `Portrait`에서 가능함.
- [UI 적용 명령](../../Assets/Editor/InterviewRefresh/ResultUiRefreshBake.cs): `ResultUiRefreshBake.Apply()`.
- [프로젝트 폰트 적용 명령](../../Assets/Editor/InterviewRefresh/ProjectFontBake.cs): `ProjectFontBake.Apply()`.

## 데이터 연결

- 결과 멤버에 CharacterId·복사된 불가 일정을 추가함. 기존 3인자 생성자와 호환됨.
- 캐릭터 ID로 시각 카탈로그를 조회함. 이름이나 목록 순서로 프로필을 추측하지 않음.
- 기존 읽기·처리 분리 및 정확도·별점·엔딩 계산 구조 사용함.

## 확인 수준

- 최종 컴파일 오류 0개·경고 0개.
- 저장된 결과 프리팹: 달력 셀 30개, 누락 0개, 칸별 프로필 풀 6개, 모집 프로필 6개.
- 결과 프리팹의 Text 128개 모두 새 폰트 참조 확인함.
- 프로젝트 업무 에셋의 기존 Noto 폰트 GUID 참조 0건, 새 폰트 참조 634건 확인함.
- 정확도 Image 두 개의 Filled 설정과 진행 버튼의 우측 앵커 확인함.
- 실제 Play 렌더·클릭·결과 데이터 표시 검증은 미실행함. 이번 요청에서는 커밋 미수행함.
