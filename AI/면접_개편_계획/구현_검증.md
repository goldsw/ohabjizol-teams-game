## 사용자 편집 방법

- MainMenuScene 또는 InterviewScene 열기 → Hierarchy에서 화면·패널 선택함.
- RectTransform 위치·크기, Text 문구·폰트, Image 색·sprite를 Inspector에서 편집하고 저장함.
- 초기 UI 표시 여부는 Hierarchy의 저장된 활성 체크를 기준으로 함.
- QuestionCatalog.asset에서 질문 Prompt·응답 문자열·normalMinimum=3/goodMinimum=5 편집 가능함.
- PortfolioCatalog.asset에서 직군/표시 상태별 카드 prefab 참조 교체 가능함.
- 원본 prefab 편집은 해당 화면/카드 자산에서 수행하고, 씬 개별 편집은 필요한 override로 저장함.

## Authoring과 초기 저장

- 런타임 authored 참조 누락 → 오류 출력·비활성 처리함. 자동 생성 fallback 없음.
- UI 생성 Bake는 Editor/EditMode에서만 실행함. Awake/OnValidate 자동 UI 생성·좌표 덮어쓰기 없음.
- 기존 prefab은 보존함. 반복 초기 저장 시 사용자 편집값을 재생성하지 않음.
- 필요 시 실제 UI 초기 저장 helper의 ApplyAndSave 사용함. 기존 자산이 있으면 재생성하지 않음.
- 원본 씬 백업: `Library/InterviewRefreshBackup`.
- 문서에는 전체 UI 재생성 명령을 제공하지 않음.
