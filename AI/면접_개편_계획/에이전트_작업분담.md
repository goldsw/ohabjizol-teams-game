## 팀장: 이관·씬·결과 UI·통합

- 기존 임시 UI를 한 번 생성해 scene/prefab 저장하고 모든 참조 연결.

- 기존 문서 UI 제거 전에 참조 전수 확인. 필요한 원본 자산 보존.
- 실제 수치 노출 제거·별점 결과 UI·엔딩 선택 UI 통합.

## 순서와 완료 기준
1. 팀장 공개 데이터/창/생명주기 계약 확정.
2. W1 데이터·규칙, W3 공통 프레임 계약 우선.
3. W2·W4·W5 병렬. W1 데이터 및 W3 참조 계약 사용.
4. 팀장 Editor 이관·씬 연결·결과 UI·Pipeline 통합 검증.
- 에이전트는 자기 파일·prefab·meta만 수정. 씬 최종 저장은 팀장만 수행.
- 사용자 승인에 따라 구현·scene/prefab 저장 완료. 사용자 선택한 실패 진행 정책은 확정값.
- 최소 검증: role 분기·색/실제수준 독립·질문 취소·문서 중복/최소화·모든 UI 리셋·별 경계·4단계 실패 포함 진행·3엔딩·저장 재진입·편집값 재열기 보존.
