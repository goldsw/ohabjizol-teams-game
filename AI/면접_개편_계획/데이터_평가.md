- 기획/아트/프로그래머마다 표시 상태 good/normal/bad 3개 자산 참조.
- 파랑/노랑/빨강 표시 상태는 지원자 최초 바인딩 때 실제 수준과 독립적으로 무작위 지정.
- 같은 지원자를 다시 열거나 질문·문서를 갱신해도 표시 상태는 바뀌지 않음.
- 실제 수준과 표시 상태를 별도 필드로 관리. 자산/색 이름으로 숨김 정답이 드러나지 않게 함.
- 자산 선택·색상 표시의 기준은 표시 상태이며, 질문 응답은 실제 수준과 일치하게 작성.
- PortfolioSpriteCatalog로 직군/표시 상태별 native UI 카드 prefab 9종 연결함. Noto 폰트 적용, 카탈로그·prefab Inspector 편집 가능함.

## 기존 정확도 보존
- 요구 능력치 r > 0인 직군만 포함.
- 직군 오차 e = min(1, abs(실제-r)/r).
- 정확도 p = round(100 × (1 - 평균 e), AwayFromZero).
- 유효 요구 직군이 없으면 기존 구현과 같이 p=100.
- 초과·부족 모두 오차로 처리.
- clear = p >= 70. 기존 정수 정확도 판정을 유지.

## 별점 기본안
- p를 0~100으로 제한.
- halfStarUnits = clamp(floor(p/10 + 0.5), 0, 10).
- 별점 = halfStarUnits / 2. 5개 이미지 각각 full/half/empty 상태로 표시.
- 예: 60%→3별, 65%→3.5별, 70%→3.5별, 75%→4별, 100%→5별.
- clear 판정은 반별 변환 전의 p 기준. 65%와 70%의 표시 별이 같아도 clear 정보는 다를 수 있음.
- S/A/B/C/Fail 표시는 별점 UI로 교체. 레거시 코드 삭제는 참조 전수 확인 후 수행.
