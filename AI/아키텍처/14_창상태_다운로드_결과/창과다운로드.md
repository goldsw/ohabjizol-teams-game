# 창·다운로드·팀 UI 계약

## 작업표시줄

- 문제: ManagedWindowTaskbarItem이 IsActive를 색상 기준으로 사용하여 포커스를 잃은 열린 창까지 회색으로 표시됨.
- 색상은 IManagedWindow.IsVisible 기준으로 계산함. 현재 PDF 구현에서 IsVisible은 IsOpen && !IsMinimized임.
- 열린 모든 창은 밝게, 최소화된 창만 회색으로 표시함. 닫힌 문서창은 기존 큐 해제 규칙을 유지함.
- 포커스·선택·정렬·클릭 최소화/복원 규칙은 기존 계약을 사용함.

## 다운로드 수명

- 문제: 패널의 coroutine·OnDisable·CloseImmediate·CancelPending이 묶여 채팅창 닫기에 다운로드가 중단됨.
- 순수 다운로드 controller가 지원자 키·세대·문서 종류별 진행률·완료 상태를 보관함.
- 세션이 활성화된 InterviewScreen/Runtime 호스트가 unscaled tick을 제공함. 패널 GameObject 활성 여부와 독립함.
- 패널 열기·닫기·OnDisable은 UI 연출만 처리함. 재표시 시 현재 진행률을 다시 표시함.
- 같은 지원자 키 재바인딩은 진행 유지함. 지원자 변경·실제 세션 종료·소유 객체 파괴는 취소·세대 무효화 경계임.
- 0.2~1초 임의 소요 시간·녹색 fill 유지함. 중복 클릭·중복 완료 이벤트를 방지함.
- 완료 요청은 원래 지원자/세대 검증 후 문서함에 저장하고 해당 문서창을 자동으로 엶. 채팅창이 닫혀 있어도 처리함.
- 새 지원자 전환 때 이전 다운로드가 새 지원자 문서로 잘못 저장되지 않도록 기존 문서 요청 식별자를 유지함.

## 현재 팀 창

- 기존 TeamSummary의 6개 슬롯·표시 합계·요구 합계 Text 참조를 InfoWindow의 Info로 이동함.
- TeamSummary/Slot0~5 구조 유지로 기존 슬롯 전용 bake와 호환함.
- 드래그 툴바·최소화·닫기와 FixedApps 상시 팀 아이콘을 제공함. 최초에는 현재 팀을 표시함.
- 고정 아이콘은 최소화/복원 및 상태색만 처리함. PDF 전용 DocumentKey 큐에 가짜 문서로 등록하지 않음.
- 지원자 변경 시 닫는 PDF·슬라이드 패널과 팀 창 수명은 분리함. 창을 닫아도 같은 세션의 팀 정보는 유지됨.
- InterviewSummaryPresenter와 ReadSelectedTeam의 표시 전용 projection을 재사용함. 실제 능력·거짓 포트폴리오 판정은 인게임 창에 노출하지 않음.
- ApplicantCenter의 저장 위치·원형 질문의 시계방향 초당 100도·작업표시줄 질문 아이콘은 유지함.
