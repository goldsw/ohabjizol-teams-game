# 정확도·결과·엔딩 계약

## 정확도와 별

- 원래 오차식 유지: 요구 능력 > 0인 항목별 min(abs(실제-요구)/요구, 1)의 평균을 100%에서 뺌. 초과·미달 모두 오차임.
- 요구가 양수인 항목이 없으면 정확도 100%임.
- 결과에 RawAccuracyPercent(double)를 보관하고, AccuracyPercent는 clamp 후 floor한 정수임.
- HalfStarUnits = floor(clamp(raw, 0, 100)/10), 별 개수 = HalfStarUnits/2임. 반올림으로 다음 반별을 미리 부여하지 않음.
- 예: 100% → 5개, 99.9% → 4.5개, 90% → 4.5개, 89.9% → 4개, 70% → 3.5개, 69.9% → 3개임.
- 기존 70% 클리어 기준 유지함. 정수 표시값도 floor이므로 raw 기준과 경계가 같음.
- 캠페인 저장은 기존 floor 퍼센트·4칸 배열·RunId·journal 구조를 사용함. floor(raw)/10과 floor(raw/10)이 같아 별 저장 필드 추가가 필요 없음.
- 기존 정수 저장값은 보존하며 원래 소수값을 추정·복원하지 않음.

## 결과 데이터·디버그

- InterviewSession.BuildResult의 동일 불변 평가 스냅샷으로 점수·일정·결과 멤버 projection을 생성함.
- 결과 전용 SelectedTeamResultMember는 이름·선발 직군·HasFalsePortfolio를 제공함.
- HasFalsePortfolio는 FakePortfolioQuality 존재 및 TruePortfolioQuality와 다름으로 판정함. Fraud 종류나 능력 차이로 대체 판정하지 않음.
- 인게임 SelectedTeamDisplaySnapshot/ReadSelectedTeam에는 실제 능력·거짓 판정 정보를 추가하지 않음.
- 결과창 왼쪽에 선발 순서대로 이름·직군을 표시하고 거짓 포트폴리오 행은 빨간색으로 표시함.
- 디버그 영역은 실제/요구 기획·프로그래밍·그래픽 합계, raw 정확도, 내림한 퍼센트와 별점을 표시함.
- Pending/null 결과일 때 이전 멤버·빨간색·디버그 값을 초기화함. 일정·별 마스크·확인 버튼은 보존함.

## 엔딩과 씬

- Good: 별 4.5개 이상, Normal: 별 3.5개 이상, Bad: 별 3개 이하임.
- 40 half-unit 척도의 기본 임계값은 36/28임. 활성 스테이지 수에 비례하여 비교하므로 현재 단일 게임잼에서는 각각 9/7 half-unit임.
- 결과 확인 버튼에서 완료 시 GoodEndingScene / NormalEndingScene / BadEndingScene으로 이동함. 미완료 시 기존 메인 복귀 흐름을 사용함.
- 새 씬은 기존 authored EndingBoard 구성을 재사용하며 씬별 고정 엔딩 종류를 직렬화함.
- 기존 EndingScene·다른 단계 정의·클리어/진행 기록·단일 실행 저장 키는 보존함.
- 누적 별 분모는 활성 스테이지 수 × 5임. 현재 단일 게임잼의 분모는 5개임.
- 기존 씬 직렬화 임계값도 36/28로 맞춤. BuildSettings의 기존 순서·활성 설정을 보존하고 새 3개 씬만 추가함.
