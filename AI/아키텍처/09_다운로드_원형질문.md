# 다운로드·원형 질문 계약
갱신일: 2026-10-14 · 설계 확정, Unity 재컴파일·prefab 적용은 부모 담당함.

## 다운로드 피드백
- 다운로드 worker 소스 구현 완료함. DownloadPanelView·InterviewDocumentPresenter·DownloadFeedbackBake는 해당 worker 소유임.
- 요청 데이터: Assets/Scripts/Interview/Data/DocumentDownloadRequest.cs의 immutable ApplicantKey·Generation·Kind임.
- Panel.typedDownloadCompleted → Presenter의 currentKey·generation·_hasApplicant 검증 → archive 저장 경로임.
- 배경 위·텍스트 아래 독립된 녹색 RectTransform으로 진행 너비 표시함. 실제 fill sprite가 없으므로 Image.fillAmount 사용하지 않음.
- 다운로드마다 0.2~1초 무작위 시간, unscaled 시간 사용함.
- Close·Bind·Disable에서 진행 취소함. key·generation·지원자 존재 검증으로 이전 요청의 저장 차단함.
- Editor 진입점: Ohabjizol.Interview.DownloadFeedbackBake.Apply(string prefabPath)임.
- 다운로드 및 원형 질문의 Unity 재컴파일·prefab Bake는 부모 담당함.
- 원형 질문 구현은 다운로드 worker 파일을 편집하지 않음.

## 원형 질문
- 새 질문 launcher 클릭 → 지원자 주변 기존 질문 버튼 5개 열기/닫기임.
- 기존 Button 인스턴스·이름·onClick·serialized 참조·질문 index·사용 수 보존함.
- Q1/Q2 및 빈 Q3~Q5 문구는 기존 Bind 경로 유지함. 질문 가능 여부는 QuestionController.CanAsk만 사용함.
- 5개 슬롯 간격은 360 / questions.Length임. 초기 각도 90도·반지름 180 Canvas 로컬 단위·회전 속도 100도/초임.
- 초기 버튼 크기는 154×48임. 반지름·각도·속도 Inspector 조정 가능함.
- portrait.TransformPoint(portrait.rect.center) → optionsRoot.InverseTransformPoint → cos/sin 반지름 위치임.
- 매 프레임 portrait 중심 추적함. unscaledDeltaTime 회전·Repeat로 위상 범위 제한함.
- 버튼 anchor/pivot은 0.5임. 그룹 자체 회전 없이 버튼 위치만 회전하여 글자 방향 유지함.
- 질문 선택 후 메뉴 열린 채 회전함. 답변 중 질문 버튼 비활성화, launcher toggle은 가능함.
- 질문을 전부 소진해도 지원자가 있으면 launcher 닫기/열기 가능함.
- 새 지원자·스테이지 완료·OnDisable·구독 해제 시 닫기 및 초기 위상 복원함.
- optionsRoot는 prefab 소유 rootCanvas 평면·영상 mask 밖에 배치함. 외부 rootCanvas이면 prefab 루트 RectTransform 대체함. 기존 host 재배치 시 인스턴스·참조 유지함. 전체 화면 Graphic/raycast 차단 없음.
- launcher와 RadialQuestionView는 optionsRoot 밖에서 활성 유지함.

## 구성 API
- RadialQuestionView.ConfigureEditor(Button launcher, RectTransform optionsRoot, RectTransform portrait, Button[] questions)
- RadialQuestionView.ResetCollapsed(), SetAvailable(bool), ToggleExpanded()
- InterviewCallView.PortraitRect: portrait RectTransform 조회만 추가함.
- InterviewViewReferences 마지막 optional 인자: RadialQuestionView radialQuestions = null
- InterviewQuestionPresenter 마지막 optional 인자: RadialQuestionView radial = null
- InterviewScreen → InterviewViewReferences → InterviewRuntime.Create → 질문 presenter 주입함.
- Bind/Unsubscribe에서 ResetCollapsed, Render에서 SetAvailable(controller.Applicant != null) 호출함.

## Editor 적용
- Ohabjizol.Interview.RadialQuestionBake.Apply(string prefabPath) 별도 호출 필요함.
- Prefab Load → 기존 질문 참조 조회 → Canvas 아래 launcher/optionsRoot 구성 → 기존 Button reparent → 저장 → finally Unload함.
- 기존 authored UI의 조기 return에 의존하지 않음. 재적용 시 기존 원형 구성 재사용함.
- 메뉴·데스크톱·문서·일정표·작업표시줄·말풍선 스타일은 기존 책임 유지함.
- 부모: Unity 재컴파일 후 지정 prefab에 Apply 호출 및 저장 필요함.
- 본 작업: 테스트 추가/실행·CLI Play·컴파일·커밋 수행하지 않음.
## 2026-10-14 적용 결과
- 다운로드 버튼 뒤 초록색 진행 영역을 0.2~1초의 무작위 시간 동안 채운 뒤 문서를 보관함. 완료는 현재 지원자 동안 유지함.
- 닫기·즉시 닫기·지원자 전환·비활성화는 세대 번호를 무효화하고 진행을 취소함. 완료 이벤트의 지원자 키·세대 검증을 적용함.
- 질문 런처로 기존 다섯 슬롯을 열고, Sin/Cos와 360/슬롯 수 간격으로 배치함. 반지름 기본 180, 회전 속도 기본 100도/초이며 Inspector에서 조절 가능함.
- 지원자 중심을 따라 위치만 회전하여 버튼 글씨는 반듯하게 유지함. 빈 질문 3~5 비활성 및 기존 질문/답변 규칙 유지함.
- 최상위 Canvas가 프리팹 소속인지 확인하고, 외부 Canvas이면 프리팹 루트 평면을 사용하도록 가드 적용함.
- DownloadFeedbackBake.Apply 및 RadialQuestionBake.Apply로 면접 프리팹 연결 완료함. 실제 CLI eval success=true, diagnostics=[], result=APPLIED 확인함.
- 적용 후 Unity 컴파일 상태: completed, failed=false, errors=[], compilationFailed=false 확인함.
- 소스 검토와 컴파일·프리팹 적용만 확인함. 플레이·시각 배치 테스트는 실행하지 않음.
