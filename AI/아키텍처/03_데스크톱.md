# 데스크톱 구조
## 앱 연결
- DesktopView의 AppBindings는 Inspector 직렬화 목록임. 아이콘·창·활성화 handler·추가 UnityEvent·초기 열림 설정을 연결함.
- 공통 DesktopView는 등록 목록의 선택·잠금·초기화·활성화·Refresh·참조 검사 담당함.
- ChungkangCodeAppHandler는 연결/게임 시작, SettingsAppHandler는 설정 연결, TutorialAppHandler는 튜토리얼 창을 담당함.
- handler가 없는 앱은 공통 창 열기 동작을 사용함.
- DesktopAppBindingDrawer는 타입 목록을 자동 수집해 Inspector에서 실행 처리 방식을 선택하도록 함.

## 이전 prefab 호환
- 새 앱 목록이 비어 있으면 기존 세 창·아이콘 참조로 기본 연결을 생성함.
- 명시된 앱 목록은 바인딩 때 기존 앱으로 다시 덮어쓰지 않음.
- 기존 serialized 이름·원본 GUID·MainMenuController의 Build/Bind 호출 계약을 유지함.
- 등록된 앱별 구독은 disable 때 해제하고 enable 때 대칭으로 연결함. 중복 아이콘·창·잘못된 handler 연결을 진단함.

## 생성과 표시
- DesktopView.Authoring의 Build/Capture/OnValidate는 에디터 생성·저장 연결 담당함.
- 실행 시 Bind는 저장된 UI를 초기화함. 실행 중 창 프레임과 UI를 다시 생성하지 않음.
- 메뉴는 모니터 클릭·부팅·카메라·로딩 씬 전환 담당함.
- 임시 주황 배경과 authored UI는 현재 에셋을 사용함.
- 기존 Build 1회·OnBuilt/BuildInfo·창 Open/Close/Refresh 계약을 사용함.
