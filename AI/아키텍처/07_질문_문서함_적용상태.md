- DocumentLibraryBake에 Ohabjizol.EditorTools import 추가하여 StageCalendarUiBake 참조 오류 CS0103 세 건 수정함.
- Unity CLI 재컴파일 완료: status=completed, failed=false, errors=[], compilationFailed=false.

- 적용 이후 재컴파일 상태도 completed·오류 없음 확인함.

## 적용 기능
- Q1: 포트폴리오 프로젝트 질문. 진짜 품질 enum과 선택적 가짜 품질 enum은 get-only이며 가짜가 있으면 진짜와 달라야 함.
- Good/Normal/Bad 각각 3개, 총 9개 대사 사용함. 예약 시 발화 확정·3초 응답 연출·취소 무효화 유지함.
- 포트폴리오 카드·이미지는 진짜 품질만 사용함. 가짜 품질은 답변 선택에만 적용함.
- Q2: 일정 질문. Q3~5는 빈 문구·클릭 불가 유지함.
- 프로젝트 일정표: 30일 중 제작일 수만큼 중복 없이 선택하여 빨간색 표시함. 스테이지 실행 중 다시 열어도 재추첨하지 않음.
- 작업표시줄: 기본 문서함·일정표 진입점 연결함. 다운로드 항목은 문서함 목록에만 표시하여 같은 위치의 작업표시줄 항목 겹침 구조 제거함.
- 다운로드 데이터: 지원자 키 + 문서 종류로 저장, 다운로드 당시 불변 packet으로 다시 열기. 다음 지원자로 넘어가도 현재 스테이지 동안 보관함.
- 지원자 전환 시 PDF·문서함·일정표·다운로드 패널 닫기. 스테이지 종료 시 저장소 정리함.

## 생성 자산 및 편집
- 문서함: Assets/Prefabs/InterviewRefresh/Documents/DocumentLibrary.prefab.
- 작업표시줄 문서함 버튼: Assets/Prefabs/InterviewRefresh/Documents/DocumentLibraryButton.prefab.
- 일정표: Assets/Prefabs/Interview/StageCalendarWindow.prefab.
- 제작일 설정: Assets/Resources/Interview/StageScheduleConfig.asset. 임시 기본값 각 스테이지 15일이며 Inspector에서 변경 가능함.
- 가짜 답변 확률: InterviewScreen Inspector, 임시 기본값 0.5. 가짜 품질 태그가 있는 지원자에만 적용함.
- 기존 면접 프리팹의 문서·일정·작업표시줄 연결만 migration 적용함. 전체 화면 Bake는 실행하지 않음.

## 확인 범위와 제한
- 실제 Unity 컴파일 및 자산 생성·프리팹 migration 완료 확인함. 실행 동작과 시각적 배치의 플레이 테스트는 수행하지 않음.
- Q2 응답은 일정표 확인 안내임. 지원자 가능일·일정 겹침 판정은 요구 미정으로 추가하지 않음.
- 스테이지 간 또는 게임 재실행 후 다운로드 문서 영구 저장은 이번 범위 아님.
- 테스트 추가·실행, 커밋, 그래프 재생성 없음. 기존 그래프와 이전 리팩토링 PASS는 이번 신규 변경의 검증 결과가 아님.
- 소스 크기 계산상 일정표 460×410에서 30개 셀 수용 가능함. 실제 화면 확인은 별도임.
