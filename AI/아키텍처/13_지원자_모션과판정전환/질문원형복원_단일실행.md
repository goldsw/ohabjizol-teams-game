# 질문 원형 복원·단일 스테이지 실행

## 확정 요구

- 기준: 2026-10-17 사용자 수정 지시임.
- 질문은 일반 창 프레임이 아닌 원형 버튼 UI임. 작업표시줄 질문 아이콘은 상시 유지하고 표시·숨김만 전환함.
- 시계방향 초당 100도, sin/cos·질문 수로 나눈 균등 각도·버튼 자체 회전 없음. 반경은 기존 180 유지함.
- 사용자 확인한 ApplicantCenter 위치 보존함. 창 밖의 독립된 편집용 중심 마커로 이동하고 실제 초상화는 재부모화하지 않음.
- 활성 실행은 입학 게임잼 하나임. 기존 4개 스테이지 정의·프로필·클리어·진행 기록은 보존함.
- 면접 대상 13명 유지, 게임잼 합격 선발 정원 6명으로 확대함.

## 질문 UI 책임

- RadialQuestionView: 표시 상태·회전 각도·원형 배치 소유함. Launcher·Window로 재위임하지 않음.
- RadialQuestionLauncher: 작업표시줄 버튼 입력 → View 토글, 아이콘 색으로 펼침 상태 반영함.
- InterviewQuestionPresenter: 질문 진행·실행 가능 여부 소유함. 일시 입력 차단은 표시·각도 상태를 초기화하지 않음.
- 새 지원자 Bind·화면 비활성 시 접힘과 시작 각도 초기화함. 표시 토글은 현재 각도 유지함.
- 기존 RadialQuestionWindow 타입·비활성 오브젝트는 직렬화 호환을 위해 보존하며 새 실행 경로에서는 사용하지 않음.
- OptionsRoot와 ApplicantCenter는 WindowLayer 직속임. Info·Toolbar의 이동·클리핑·닫힘과 독립함.
- RadialQuestionBake는 위 연결만 저장함. 전체 화면·문서 UI 재생성은 수행하지 않음.
