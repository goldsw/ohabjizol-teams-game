## 캐릭터: 연결 누락 가능성 높음

- 화면의 강이안 및 요구치 22/18/26은 StagePrototypeData.SecondYear 데이터와 일치함.
- StageStatsCatalog.asset은 입학 게임잼만 useOverride=true, 나머지 3단계는 false임.
- ScriptableStageDefinitionProvider.Get은 override가 꺼져 있으면 프로토타입을 그대로 반환함.
- Applicant 생성자의 CharacterId 기본값은 null이며 전달값을 그대로 보관함. 신규 SO 프로필은 character-01~13을 전달하는 별도 경로임.
- InterviewApplicantPresenter는 CharacterId로 VisualCatalog 조회 실패 시 SetPose(null)을 호출함. CallView는 이때 빈 스프라이트·어두운 블루 색으로 표시함.
- 따라서 기존 단계 데이터의 ID 미이행과 공통 idle/talk 제거가 결합한 회귀가 가장 유력함. 카탈로그 미할당·Idle 누락도 같은 표시가 가능함.
- 현재 세션 Stage/CharacterId 실측은 CLI main-thread 5000ms timeout으로 미확인임. 실제 런타임 null을 확정한 것은 아님.

## 질문창: 닫힘 상태와 배치를 분리해 확인 필요

- RadialQuestionView.SetAvailable(false)는 ResetCollapsed → optionsRoot 비활성 및 Window.Close를 호출함. true는 가용성만 바꾸며 창을 다시 열지 않음.
- QuestionPresenter.SetInputBlocked → Render가 이 가용성 API를 호출함. Bind/OnEnable의 ResetCollapsed도 존재하나 해당 경로는 기존부터 있어 마지막 커밋의 직접 회귀라고 단정하지 않음.
- 입력 잠금 정책과 창 수명/표시 상태가 결합된 구조는 확인됨.
- PositionQuestions는 portrait의 월드 중심을 optionsRoot 좌표로 변환하여 매 프레임 배치함. 이동 가능한 창의 Info와 외부 portrait라는 두 좌표 기준이 있어, 실제 부모·클리핑 경계 확인이 필요함.
- 7672eef의 InterviewScreen.prefab diff에는 Transform 변경이 없고, 공통 idle/talk 참조가 VisualCatalog 참조로 교체됨.
- 질문창 삭제·화면 밖 이동·클리핑 중 어느 현상인지는 실제 IsOpen/active/Rect 값 미확인으로 보류함. 그리드 문제로 단정할 근거 없음.
