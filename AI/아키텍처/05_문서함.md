# 스테이지 문서함

## 저장과 수명
- DocumentKey: ApplicantKey ordinal 비교 + DocumentKind 조합임.
- StageDocumentStore: Dictionary 조회와 다운로드 순서의 읽기 전용 목록 소유함.
- AddOrGet: 동일 키 중복 다운로드 제거하며 최초 snapshot·순서 유지함.
- ApplicantDocumentPacket: sealed·get-only 불변 객체이므로 다운로드 시 참조 그대로 보관함.
- DownloadedDocument: Key·PacketSnapshot·DisplayName·Order 소유함.
- BindApplicant: 현재 바인딩 변경, 다른 지원자로 전환 시 모든 PDF·문서함 닫음.
- ClearApplicant: 현재 바인딩 해제·모든 창 닫기, 스테이지 저장 유지함.
- ResetStage / Dispose: 저장·행·PDF 인스턴스 정리함. Runtime.Dispose에서 호출함.

## 표시와 API
- 고정 문서함 버튼: 현재 지원자·다운로드 유무와 무관하게 더블클릭 OpenLibrary 호출함.
- DocumentLibraryView: InfoWindow 드래그·닫기·최소화·복원 사용함.
- Content: ScrollRect·VerticalLayoutGroup·ContentSizeFitter, 간격 8·최소 행 168×52 사용함.
- DocumentTaskbarItem: 목록 행 재사용, 지원자 이름 포함, 더블클릭 OpenDocument(key) 호출함.
- PDF: 현재 packet 대신 저장된 PacketSnapshot으로 Bind함.
- GetState(kind): 현재 지원자 호환 API, 바인딩 없으면 Closed 반환함.
- GetState(key): 과거 지원자 창 포함 keyed 상태 반환함.
- 다운로드 행은 문서함 Content에만 생성함. 런타임 창 좌표·고정앱 생성 없음.

## 에디터 연결
- DocumentsUiBake.BuildAssets: 기존 PDF prefab 보존·신규 문서함 prefab 생성함.
- DocumentLibraryBake.BuildAssets: Library 및 고정 문서함 버튼 prefab 없을 때만 생성함.
- DocumentLibraryBake.Apply(string prefabPath): LoadPrefabContents → 고정앱·창 scoped migration → SaveAsPrefabAsset → finally UnloadPrefabContents 수행함.
- InterviewScreen.BakeDocumentAppsUi: EditMode에서 기존 화면 참조에 연결하는 migration임.
- 신규 prefab: Assets/Prefabs/InterviewRefresh/Documents/DocumentLibrary.prefab 및 DocumentLibraryButton.prefab.
- 기존 PDF 행 prefab은 수정 없이 유지하며 신규 library가 행 LayoutElement를 보완함.
- taskbar FixedApps HorizontalLayoutGroup에 고정앱 배치함. 문서함·일정표 두 고정앱을 간격 8·확장 false로 배치함. 기존 화면 root·좌표·art 보존함.

## 검증 경계
- 이 작업에서 테스트·컴파일·prefab bake 실행하지 않음.
- 부모 담당: Unity 재컴파일 → BuildAssets → 화면 migration → prefab/scene 저장 및 동작 검증함.

## 일정표·질문 통합
- StageScheduleConfig.GetProductionDays(StageId) → StageCalendarState 생성 → StageCalendarWindow.Bind(state, stageName) 연결함.
- Runtime.Create에서 상태 한 번 생성함. Enable·재열기 시 재추첨 없음.
- 일정표: 고정 버튼 클릭 복원, 지원자 전환·disable 시 닫음.
- fakePortfolioAnswerChance: Inspector Range(0,1)·기본 0.5 → QuestionController 생성자 주입함.
- 일정표·질문 data/view 소스는 별도 제작자 소유임.
