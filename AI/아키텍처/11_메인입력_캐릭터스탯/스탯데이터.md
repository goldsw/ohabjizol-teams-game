# 스탯 데이터
## source 해석과 SO 구조
- 각 캐릭터에 기획/프로그래밍/아트 3개 직군 variant가 있음. 총 13개 캐릭터 SO 각각 RoleProfiles[3] 저장함.
- B/C:E는 해당 profile의 기본 직군/기획·프로그래밍·아트 범위, G/H:J는 선택적 허위 직군/허위 범위임.
- 범위 문자열은 포함 Min/Max 정수 범위로 파싱함. 평균·대표값·역할 추정·임의 숫자 생성 금지함.
- IntRange 계약: Min, Max, Min <= Max, 개인 범위 양끝은 0..10임.
- RangeSet 계약: Planning, Programming, Art 각각 IntRange임. 0은 유효값이며 누락과 구분함.
- ApplicantRoleProfile 계약: DomainPrimaryRole, BaseRangeSet, HasFakeRanges/FakeRangeSet, 선택적 FakeRoleMetadata, 원본 sheet/row/cell 참조임.
- CharacterStatsAsset 계약: 안정 CharacterKey, source 이름, RoleProfiles[3], TruePortfolioQuality, IsTemporaryPortfolioQuality임.
- ApplicantCatalogAsset는 13개 CharacterStatsAsset 참조를 직렬화함. 캐릭터키·직군 profile 중복/누락은 DefinitionIssue로 기록함.
- DTO는 raw 기본/허위 범위 문자열과 원본 위치를 보존하고 SO 범위로 명시 변환함. 빈칸을 0·전체 범위로 대체하지 않음.
- 기존 지원자와 이름·역할로 추측 매핑하지 않음. 새 지원자는 source 캐릭터와 선택 profile에서 생성함.
- 문서는 기존 역할 템플릿 placeholder 허용함. 미정 정보를 사실로 작성하거나 기존 수치 문구를 복사하지 않음.

## 직군 선택과 1회 샘플링
- 면접 런 구성 시 캐릭터마다 유효 profile 하나 선택함. 기본은 3직군 균등 무작위 선택이라는 부모 가정이며 사용자 확정사항과 구분함.
- ApplicantMaterializer.Create(CharacterStatsAsset source, JobRole role, Random random)는 선택 profile의 각 BaseRange에서 정수 1회 샘플함.
- 포함 범위 추출은 random.Next(Min, Max + 1) 계약임. 샘플 결과를 ExpectedSkills와 ActualSkills에 같은 값으로 저장함.
- HasFakeRanges이면 각 FakeRange에서 독립 샘플해 FakeSkills에 저장함. DisplayedSkills = FakeSkills ?? ExpectedSkills 적용함.
- 스탯 가짜값은 실제보다 낮아야 한다는 규칙 없음. 겹침·동일값·상향·하향을 범위 외 규칙으로 제한하지 않음.
- 기본 직군 B → Applicant.PrimaryRole임. G는 FakeRoleMetadata로 보존하고 직군 UI에는 사용하지 않음.
- 런 snapshot에 선택 직군과 실제/예상/가짜 샘플 결과를 보존함. 화면 갱신·재활성화·문서 열기·세션 clone에서 재샘플 금지함.
- 무작위 공급자는 조립부에서 전달함. 캐릭터 SO의 원본 범위를 샘플 결과로 덮어쓰지 않음.

## 포트폴리오 품질과 전달 보존
- FakeStats와 기존 FakePortfolioQuality는 별개임. 포트폴리오 가짜 품질에만 기존 하향 규칙 적용함.
- 원본 표에 포트폴리오 품질 없음. 기존 prototype/역할 템플릿 품질 다양성을 유지하고 새 SO의 품질은 명시적 임시기본으로 관리함.
- TruePortfolioQuality와 IsTemporaryPortfolioQuality로 임시값임을 기록함. 표 추출값 또는 기존 인물과 대응한 값으로 주장하지 않음.
- Applicant는 ExpectedSkills, ActualSkills, 선택적 FakeSkills, FakeRoleMetadata를 보존함. 기존 생성자 유지·새 필드용 overload 추가 계약임.
- InterviewSession.CopyApplicants()는 이미 샘플된 세 스탯·선택 기본직군·허위직군 metadata를 그대로 전달함. 범위 파싱·무작위 직군 선택을 다시 수행하지 않음.
- 포트폴리오 품질의 기존 세션 생성 정책은 스탯 샘플링과 독립 유지함.
- ApplicantDocumentPacket에는 DisplayedSkills만 전달함. ActualSkills와 실제값을 유추시킬 원본 기본 점수의 별도 UI 전달 금지함.
