# 문서창·작업표시줄 계약

- 다운로드: StageDocumentStore에 불변 스냅샷 보관함. 씬 참조 보관 금지함.
- DownloadedDocument.TaskbarInfo: DisplayName / PDF / null descriptor 반환함.
- 관리 대상: PDF만 IManagedWindow 구현함. 문서함·일정표는 고정 launcher 유지함.
- Workspace: OpenDocument 시작 시 Queue.TryGetWindow(DocumentKey, out IManagedWindow) 확인함. 존재하면 즉시 반환함. Minimized도 존재 인정함. Restore/Maximize/focus 수행 금지함.
- 신규만 Instantiate, Bind snapshot, Initialize(document, Queue), Maximize함. 재활성화는 작업표시줄 아이콘으로만 수행함.
- 동일 정보 identity: DocumentKey(applicantKey + kind)임. title 비교 금지함. Dictionary는 GetState/cleanup 전용, 중복 authority는 Queue임.
- IManagedWindow.DocumentKey / Queue.TryGetWindow 추가 계약 따름. Queue.Register도 같은 DocumentKey 중복 방어함.
- Closed: key lookup 제거함. 실제 destroy와 queue unregister는 PDF 담당함. 다운로드 기록 유지함.
- CloseAllWindows: viewer snapshot의 Close 호출, library.Close, Queue.ClearFocus 수행함.
- 지원자 변경: 모든 창 닫음. stage archive 보존함. ResetStage만 archive 초기화함.
- Queue: 순서 유지 Windows / ActiveWindow / Changed 제공함. 뷰 비활성화 시 queue 보존함.
- Taskbar view: Changed 구독, 등록된 창만 item 생성함. 순서대로 sibling 배치함. 미등록 항목만 제거함.
- Item: descriptor title/icon 표시함. 단일 click → active이면 Minimize, 그 외 Maximize함.
- 색상: active 밝은 주황, inactive 회색 유지함.
- 고정 launcher와 dynamic items 별도 container 사용함. dynamic ScrollRect 수평 overflow 사용함.
- Layout: item 고정 168×52, spacing 8, taskbar 폭 900 이상 확보함.
- 비PDF 전면화: focusRoot의 WindowToolbar.Foregrounded 구독 → ClearFocus함.
- PDF focus/body/drag: core FocusRequested 처리에 위임함.
- Lifecycle: view OnDisable 구독 해제, OnEnable 재구독함. item OnDestroy click 해제함.
- Migration: TaskbarWindowBake.Apply(prefabPath)로 기존 screen의 taskbar만 확장함.
- 기존 PdfViewer 및 document library row prefab GUID와 버튼 binding 유지함.
- Core API: descriptor / IManagedWindow / TaskbarQueue / Foregrounded는 core worker 계약 따름.
- 검증: 부모의 core 완료·컴파일 후 Apply 실행 필요함. 이 작업에서 test/Unity/commit 실행 금지함.

## 2026-10-14 적용 결과
- 대사 9개를 질문자의 생각으로 변경하고 품질별 디버그 접두어 적용함.
- 다운로드 데이터에 제목·아이콘 정보 descriptor 보관, 생성된 PDF가 Initialize에서 작업표시줄 큐에 등록함.
- 실제 Queue<IManagedWindow> 사용함. 최소화·포커스 변경은 등록 순서를 유지하고, 닫기는 등록·아이콘·창 객체를 제거함. 다운로드 기록은 유지함.
- 활성 아이콘 클릭은 Minimize, 비활성 아이콘 클릭은 Maximize 호출함. Maximize는 기존 크기로 표시·앞으로 가져오기 의미임.
- 동일 정보 여부는 DocumentKey(지원자 키 + 문서 종류)로 Queue.TryGetWindow가 확인함. 창이 있으면 최소화 상태까지 포함하여 문서함의 열기 요청을 무시함.
- 3초 응답 중 오른쪽 Image 말풍선과 점 반복 표시, 응답 완료·취소·지원자 전환·비활성화 시 숨김 적용함.
- TaskbarWindowBake.Apply 및 InterviewSpeechBubbleBake.Apply로 면접 프리팹 연결 완료함. CLI eval success=true, diagnostics=[] 확인함.
- 최초 적용 시 Play Mode 가드가 차단하여 Play 모드를 종료한 뒤 적용함. Editor는 Edit Mode에 남겨 둠.
- 기존 달력·문서함 재Migration 없이 작업표시줄 자산과 연결만 적용함.
- Unity 재컴파일 완료: status=completed, failed=false, errors=[], compilationFailed=false 확인함.
- 소스 수명·등록 해제·중복 차단 검토 완료함. 실제 플레이·아이콘 클릭·말풍선 시각 배치 테스트는 실행하지 않음. 테스트 추가·커밋·그래프 재생성 없음.
