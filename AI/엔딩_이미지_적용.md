# 세 엔딩 이미지 적용

## 확인된 상태

- 세 엔딩 씬에 네이티브 Aseprite Sprite 참조는 이미 존재함. PNG 미참조 자체는 누락 원인이 아님.
- 이미지가 들어간 패널은 화면 일부인 1536×345.6 영역임. 세 씬 모두 편집 상태에서는 GoodPanel만 활성화되어 있음.
- `EndingBoard.Awake()`는 완료 기록이 없으면 고정 엔딩 씬도 이미지를 숨기고 준비중 문구를 표시함.

## 수정안

- 좋음 → `Good_Ending`, 보통 → `Normal_Ending`, 나쁨 → `Re_Bad_Ending` 매핑 유지함.
- 원본: `Assets/Art/Ending/Source/Aseprite/텍스트 X/`의 같은 이름 Sprite 사용함. 원본 파일 수정 없음.
- 기존 EndingBoard 패널을 화면 전체 배경으로 확장함. 비율 유지·흰색·Simple Image 적용함.
- 배경은 기존 버튼·텍스트 뒤로 배치함. 이야기 문구는 그림 중앙을 가리지 않도록 하단으로 옮김.
- 세 전용 씬은 각 고정 엔딩 패널만 활성화하여 편집 상태와 직접 실행에서도 해당 그림을 표시함.
- 완료 기록이 없는 고정 씬은 누적 별 숫자를 빈 값으로 표시함. 일반 EndingScene의 완료 대기 동작은 유지함.
- 재적용 시 같은 배치가 유지되도록 기존 아트 연결 API에 반영함. 엔딩 판정 점수·씬 전환 경로·결과 화면은 수정하지 않음.

## 대상·완료 조건

- 코드: `Assets/Scripts/Interview/Result/EndingBoard.cs`.
- 씬: `GoodEndingScene`, `NormalEndingScene`, `BadEndingScene`.
- 세 씬의 고정 종류·선택 패널·이미지 참조·전체 화면 앵커 저장 확인 필요함.
- 컴파일 확인함. Play·게임 완료 시뮬레이션·커밋은 요청 범위에 포함하지 않음.
