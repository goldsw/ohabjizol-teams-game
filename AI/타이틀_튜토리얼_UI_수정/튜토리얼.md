# 튜토리얼 순서·대사

## 도입: 상사 등장

지원자 영상 영역을 패널로 가리고 그 위에 상사 인물을 표시함. 대사별 다음 입력으로 이동함.

1. 곧 게임잼 면접일이네.
2. 항상 수고하고 있어.
3. 최근에 포트폴리오를 허위로 작성해서 면접에 뽑히는 사람들이 많다고 하는데.
4. 조심하는 게 좋을 거야.
5. 허위 지원자를 어떻게 구별했냐고?
6. 팁을 좀 주자면.

상사와 가림 패널을 페이드아웃한 뒤 실제 게임 UI 안내로 이동함.

## 실제 조작 단계

1. 다운로드 사이드바 버튼 강조: `자, 이걸 누르면 다운로드 버튼이 뜰 거야.` → 실제 사이드바 열림.
2. 포트폴리오·지원서 다운로드 버튼 강조: `자, 포트폴리오와 지원서를 다운로드하자고.` → 두 문서 다운로드 완료.
3. 사이드바 닫기 강조: `이제 사이드바를 닫고.` → 실제 닫힘.
4. 열린 문서 창 전체 범위 강조: `자, 이게 방금 열었던 파일들이야.` → 아무 곳 클릭하여 계속.
5. 문서함 아이콘 강조 → 실제 문서함 열림.
6. 문서함 설명: `잘했어. 이곳에는 네가 다운받은 문서들이 정리되어 있지.` → 다음 입력.
7. 문서함 닫기 강조 → 실제 닫힘.
8. 질문 아이콘 강조: `자, 이제 한번 면접자에게 질문을 해볼까?` → 질문 메뉴 열림.
9. 포트폴리오 질문 강조: `이걸로 포트폴리오에 관해 질문할 수 있지.` → 실제 질문 처리.
10. 일정표 질문 강조: `이걸로 일정표에 대해 질문할 수 있어.` → 실제 질문 처리.
11. 일정 설명: `일정표상 개발일에 개발을 못 하면 계획에 차질이 생기니 주의하라고.` → 다음 입력.
12. 질문 아이콘 다시 강조 → 질문 메뉴 닫힘.
13. 현재 팀 아이콘 강조: `자, 현재 팀은 이 아이콘으로 확인해.` → 실제 현재 팀 창 열림.
14. 일정표 아이콘 강조: `이건 일정표 아이콘이야. 현재 배정된 일정표를 볼 수 있지.` → 실제 일정표 창 열림.
15. 메모장 아이콘 강조: `이건 메모장인데, 같은 질문을 여러 번 하면 실례니 잘 메모해두라고.` → 실제 메모장 열림.

다운로드 완료 후 문서 자동 열림·기존 중복 방지·다운로드 중 사이드바 닫기 유지함. 설명으로만 진행하지 않음.

## 마무리: 상사 재등장

다시 지원자 영상 영역을 가리고 상사를 페이드인함.

1. 이런 식으로 하면 되고, 난 다른 팀플 때문에 가보도록 하지.
2. 수고해.

`튜토리얼이 끝났습니다. 아무 곳이나 클릭하여 게임 시작` 표시함.
마지막 클릭 → 안내 확인 기록 저장 → MainMenuScene 복귀함.
상사 전용 아트가 없을 경우 지원자와 다른 기존 인물 및 `상사` 라벨을 임시로 사용하고 Inspector 교체 참조를 제공함.
