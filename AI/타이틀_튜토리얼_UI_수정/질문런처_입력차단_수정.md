# 질문 런처 입력 차단 수정

## 원인 확정

- 사용자가 유지한 일반 InterviewScene Play 상태에서 클릭 없이 상태·Raycast 결과를 읽음.
- `RadialQuestionLauncher` 버튼: enabled=true, interactable=true, 런타임 리스너 1개, persistent 리스너 0개.
- 질문 뷰: 활성, `_available=true`, `_expanded=false`. 질문 선택지 루트는 닫힌 상태임.
- 버튼 중심 `(1830.80, 32.40)`의 첫 Raycast 대상은 `Taskbar/DownloadedItems/ManagedWindows` 배경(depth 128)이었음.
- 실제 질문 버튼은 두 번째 대상(depth 117)이므로 클릭을 받지 못함.
- `InterviewScreen.DocumentAuthoring.cs`가 이 투명 배경에 `raycastTarget=true`를 설정하고 있었음.
- 튜토리얼 오버레이나 질문 가용성 문제가 아닌 공통 작업표시줄 배경의 입력 차단으로 확인함.

## 적용

- 사용자 승인 후 Play 종료함.
- [UI 작성 코드](../../Assets/Scripts/Interview/UI/InterviewScreen.DocumentAuthoring.cs): ManagedWindows 배경 `raycastTarget=false`로 변경함.
- [공통 화면 프리팹](../../Assets/Prefabs/InterviewRefresh/InterviewScreen.prefab): 같은 속성만 false로 저장함.
- InterviewScene·TutorialScene 모두 공통 프리팹의 false 값을 상속함. 해당 속성의 추가 씬 수정은 필요하지 않았음.
- 문서·창 항목 버튼과 스크롤 컴포넌트, 원래 배치는 변경하지 않음.

## 확인 수준

- 컴파일 오류 0개·경고 0개.
- 프리팹 저장 및 두 씬의 적용값 확인함.
- 수정 후 Play 재실행·클릭 검증은 미실행함.
- 실측 로그: `Logs/TutorialRefresh/question-launcher-live.json`.
- 적용 로그: `Logs/TutorialRefresh/question-raycast-apply.json`.
- 백업: `Logs/TutorialRefresh/Before/QuestionRaycast-20261020T210811939/`.
- 이번 수정은 커밋 미수행함.
