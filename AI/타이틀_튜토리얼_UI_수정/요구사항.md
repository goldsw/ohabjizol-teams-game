# 요구사항·완료 조건

## 캐릭터 이름

- 캐릭터 ID·시트 순서·랜덤 등장 순서·능력치·직군 규칙은 유지함. 표시 이름만 변경함.
- 01 강서윤 / 02 차도현 / 03 백하린 / 04 윤세아 / 05 한유진 / 06 서도윤.
- 07 정미소 / 08 이가은 / 09 백시현 / 10 임태오 / 11 김재하 / 12 오지안.
- ScriptableObject 및 향후 데이터 생성 경로에서 같은 이름을 사용함.

## 문서·질문·버튼

- 문서함 문서는 단일 클릭으로 기존 창 열기 요청을 보냄. 같은 문서의 중복 창 방지는 유지함.
- 질문 버튼의 회전 동작 중지함. 배치는 고정하고 질문 실행·창 토글·드래그·UI 가림 문제 확인함.
- 모든 공통 버튼에 반투명 활성 표시 배경을 추가함. 창 열림·토글 선택 상태는 이 배경으로 표현함.
- 활성/비활성 전환에 따른 아이콘·라벨 색 덮어쓰기 제거함. 클릭 시 눌림 피드백 및 버튼 고유 의미색은 유지함.
- 활성 배경은 클릭을 가로채지 않음. 일반 버튼의 선택·포커스 상태도 지원함.

## 시작 화면

- 앱 실행은 MainMenuScene에서 시작함. 빌드 시작 씬과 에디터 기본 Play 시작 씬에 반영함.
- 메인 화면 앞에 전체 화면 타이틀 오버레이를 표시함.
- `아무 키나 눌러 시작 !` 문구가 반복 점멸함. 입력 후 메인 화면 조작 가능함.
- 타이틀을 닫은 동일 입력이 뒤쪽 UI까지 클릭하지 않도록 처리함.
- 튜토리얼에서 메인 화면으로 돌아올 때 타이틀을 다시 강제하지 않음.

## 튜토리얼 진입·종료

- 첫 PLAY 입력은 시작/건너뛰기 선택을 제공함. 시작 시 전용 튜토리얼 씬으로 이동함.
- 건너뛰기는 안내 확인 기록을 남기고 메인 화면으로 복귀함. 다음 PLAY는 일반 게임을 시작함.
- 메인 컴퓨터의 튜토리얼 버튼으로 언제든 재실행 가능함.
- 종료 후 안내 확인 기록을 저장하고 메인 화면으로 복귀함. 그다음 PLAY가 일반 게임을 시작함.
- 튜토리얼의 지원자·다운로드·문서·선택 결과는 일반 게임 저장·결과·스테이지 기록과 분리함.
- 실제 게임 UI의 입력/완료 이벤트에 따라 단계 이동함. 설명 단계는 다음 또는 아무 곳 클릭으로 이동함.
- 강조 영역은 대상의 RectTransform을 따라가며 짧은 안내 문구와 테두리를 표시함.
- 조작 단계에서는 대상 입력만 허용하고, 설명 전용 단계는 배경 클릭을 소비함.
- 상사는 지원자 영상 위 별도 패널·인물 Image·대사로 표시함. 등장/퇴장 페이드 지원함.

## 프리팹·적용

- 인게임 씬의 공용 UI 구조·버튼 연결·프로필·창 등 필요한 수정사항을 원본/적절한 변형 프리팹에 반영함.
- 씬 전용 외부 참조는 프리팹에 끊어진 참조로 저장하지 않고 호스트/바인더에서 연결함.
- 기존 스테이지 정보·능력치·6인 팀·점수·엔딩 조건·아트 원본 보존함.
- 프리팹 원본 자식 임의 삭제·전체 Unpack·정리용 무관 변경 금지함.
- 컴파일·씬 직렬화·참조 상태 확인함. 사용자 요청 없는 Play/테스트/커밋은 실행하지 않음.
