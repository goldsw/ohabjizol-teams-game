# 적용 결과

## 사용 흐름

- 실행 → MainMenuScene의 검정 타이틀·점멸 문구 → 아무 키/마우스/게임패드/터치 입력 → 기존 메인 컴퓨터 화면임.
- 첫 PLAY → 튜토리얼 시작/건너뛰기 창. 시작은 전용 TutorialScene, 건너뛰기는 확인 기록 후 메인 화면 유지함.
- 튜토리얼 완료 → 확인 기록 저장 → 메인 화면 복귀. 이후 PLAY는 일반 게임으로 진입함.
- 메인 컴퓨터의 기존 튜토리얼 아이콘·창에서 재실행 가능함.
- 확인 기록은 PlayerPrefs `ohabjizol.tutorial.seen.v1` 한 항목임. 씬 제작 과정에서는 기록하지 않았음.

## 반영 내용

- character-01~12 이름 및 정본 JSON·재수입기 이름 규칙 반영함. 13번·직군·스탯 범위·허위 스탯·랜덤 등장 순서 보존함.
- 문서함·문서 항목 단일 클릭 적용함. 동일 정보 문서 창 중복 방지 유지함.
- 질문은 지원자 기준 고정 원형 배치임. 회전 제거·전면 표시·화면 재활성화 후 사용 가능 상태 보존함.
- 공통 버튼의 활성/비활성 색 변화 대신 반투명 ActiveBackground 사용함. 눌림 피드백·기존 의미색 유지함.
- 고정 창·작업표시줄 아이콘은 다른 창으로 포커스가 이동해도 열린 상태 배경을 유지함. 배경 자체는 입력을 가로채지 않음.
- 상사 도입 6개·실제 안내 15단계·마무리 2개·완료 안내 구성함. 창 열림/닫힘, 두 다운로드 완료, 실제 질문 처리 완료를 관찰하여 진행함.
- 설명은 다음/배경 클릭, 조작은 강조 대상 영역만 입력 허용함. 키보드의 다른 UI 선택·Submit 차단 후 종료 시 복원함.
- 상사는 영상 가림 패널·인물 Image·페이드·대사로 표시함. **12번 캐릭터 Idle 임시 사용**, `TutorialOverlay.supervisorIdle`에서 교체 가능함.
- 튜토리얼은 별도 호스트·새 지원자·새 일정·새 문서 세션을 사용함. 캠페인 저장/복구·StageSelection 변경·합격/불합격·결과 전환 차단함.

## 프리팹·씬

- 현재 인게임 미저장 편집본을 복사 보관한 뒤 InterviewScreen 공용 프리팹에 UI 구조·추가 오브젝트·참조를 병합함. 외부 씬 오브젝트 참조 0개 확인 후 적용함.
- 공용 프리팹은 InterviewScene과 TutorialScene에서 함께 사용함. TutorialScene의 비활성 wrapper는 Awake 전 호스트 주입을 위한 구조임.
- 변경 프리팹: `InterviewScreen.prefab`, `Desktop.prefab`, `Documents/PdfViewer.prefab`, `Documents/ManagedWindowTaskbarItem.prefab`.
- 변경/추가 씬: `InterviewScene`, `MainMenuScene`, `TutorialScene`. 빌드 첫 활성 씬 및 에디터 Play 시작 씬은 MainMenuScene임.
- 기존 스테이지 정보·결과/엔딩 씬·아트 원본 보존함.
- 재적용: Edit 모드에서 InterviewScene을 연 뒤 `TutorialPrefabMergeBake.Apply()` → `TutorialRefreshBake.Apply()` 순서임. 대상 씬 편집 내용도 저장되므로 필요한 내용만 남긴 뒤 실행함.
