# 청강코드 접속 버튼·튜토리얼 아이콘 적용

## 적용 동작

- 청강코드 바탕화면 아이콘: 청강코드 창만 표시함.
- 창 오른쪽 아래 새 게임 버튼: 새 실행 초기화 → 기존 연결 대기 → 기존 메인 컨트롤러의 게임 시작 경로 호출함.
- 첫 플레이의 튜토리얼 시작/건너뛰기 정책과 기존 로딩·카메라 전환 경로 유지함.
- 연결 중·연결 완료 후 버튼 중복 실행 차단함. 창 닫기 시 기존 연결 취소 처리 유지함.
- 대기 안내를 “새 게임을 눌러 접속하세요.”로 변경함.
- MainMenuScene의 TutorialIcon 비활성 오버라이드를 활성으로 변경함. 기존 바탕화면 위치 및 튜토리얼 실행 연결 사용함.
