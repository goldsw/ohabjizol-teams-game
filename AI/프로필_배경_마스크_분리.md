# 프로필 배경·마스크 분리

## 수정 기준

- 중앙 지원자 위치는 `DiscordViewRoot/MainVideo/Portrait` RectTransform으로 조정함. `ApplicantCenter`는 원형 질문 중심임.
- 이번 변경 대상은 현재 팀·통화 채널의 작은 프로필임. 중앙 영상 위치·크기 변경 없음.
- 얼굴 내부 오프셋을 위로 8 UI 단위 이동함. 기존 배율 1.466667·상단 피벗 유지함.

## 목표 계층

```text
SlotGroup
  Profile                 # 56×56 레이아웃 셀
    ProfileBackground     # 상시 표시 배경 Image
    ProfileMask           # 스텐실 전용 Image + Mask
      Portrait            # 얼굴 Image
  Caption
```

- 배경은 `profile` 원형 Sprite를 어두운 색으로 표시함. 기존 Placeholder를 재사용하여 빈 자리도 같은 배경으로 표시함.
- 마스크는 원형 Sprite·`showMaskGraphic=false` 유지함. 얼굴만 Mask 자식으로 렌더링함.
- Profile의 크기를 LayoutElement로 고정하고 배경·마스크는 내부 전체 영역에 배치함. 배경과 마스크를 각각 조정할 수 있음.
- `profile_bg`는 가로형 프레임 이미지이므로 원형 배경으로 사용하지 않음.
- TeamWindow Info의 Team_List 배경 Sprite는 빈 원형 자리와 중복되므로 단색 패널로 전환함. 제목·행·통계·창 버튼 유지함.

## 구현·완료 조건

- 대상: `InterviewTeamSlotView.cs`, `InterviewScreen.CallChannelAuthoring.cs`, `InterviewScreen.TeamWindow.cs`.
- 새 생성·기존 편집 적용 모두 같은 구조 사용함. 오프셋 이동은 직렬화 표시로 1회만 적용함.
- 현재 팀 6개·통화 채널 1개 씬 저장 후 배경·마스크 분리 및 오프셋 `-10` 유지 확인함.
- 기존 데이터·원본 아트·프리팹 원본 자식 삭제·전체 Unpack·중앙 영상 수정 금지함.
- Play·동작 테스트 생략함. 커밋은 사용자 후속 요청에 따라 별도 진행함.

## 적용 결과

- 현재 팀 6개·통화 채널 1개 분리 후 씬 저장·재로드 확인함.
- 7개 모두 `Profile/ProfileBackground`와 `Profile/ProfileMask/Portrait` 별도 계층, 셀 56×56, 마스크 Graphic 비표시 확인함.
- 얼굴 오프셋 `-18 → -10`, 배율 1.466667 유지함. 런타임 바인딩은 저장된 위치를 사용함.
- 배경 색·Sprite·Transform은 스텐실과 독립됨. 지원자 전환 시 배경 설정을 덮어쓰지 않음.
- TeamWindow Info를 단색으로 전환하여 Team_List의 빈 원과 겹치지 않게 함.
- Unity 컴파일 오류 0개·경고 0개. Play·동작 테스트 미실행함.
- 최종 열린 씬 MainMenuScene, 미저장 변경 없음. 근거: `Logs/ProfileBackgroundSplit/apply.json`, `recompile.json`.
