# 창 활성화 구현·검증 기록

## 상태
- 사용자 설계 승인 후 gpt-6.1-sol / low로 공통 창·메뉴·면접 구현 분할 완료.
- 원인 탐색·설계는 gpt-6.1-sol / high 사용.
- 최신 상태: Pipeline 연결 후 컴파일·씬 초기 설정 저장·자동 검증 완료. 아래 배치 잠금 내용은 초기 실행 이력임.
- 커밋 미수행.

## 변경 파일과 동작
- [WindowToolbar.cs](../../Assets/Scripts/UI/WindowToolbar.cs): Build의 강제 숨김 제거. ApplyInitialState(bool) 최초 1회 적용.
- [WindowFactory.cs](../../Assets/Scripts/UI/WindowFactory.cs): 생성 객체 비활성화 후 컴포넌트·콘텐츠 구성.
- 초기 true는 Open·갱신·Opened 경로, false는 최초 Closed 이벤트 없이 숨김.
- 중복 초기화는 닫힌 창을 재개방하지 않음. IsOpen은 개별 activeSelf 의미 유지.
- [MainMenuController.cs](../../Assets/Scripts/Presentation/MainMenuController.cs): 직렬화 initialWindows 추가. 소유 GeneratedDesktopRoot만 정리하고 기존 Canvas 자식 보존.
- [DesktopView.cs](../../Assets/Scripts/Presentation/Desktop/DesktopView.cs): 바인딩·구독 후 초기 상태 적용. 초기 청강코드 표시가 자동 접속을 시작하지 않음.
- [DesktopInitialState.cs](../../Assets/Scripts/Presentation/Desktop/DesktopInitialState.cs): codeOpen/settingsOpen/tutorialOpen, 기본값 모두 false.
- [InterviewScreen.cs](../../Assets/Scripts/Interview/UI/InterviewScreen.cs): 직렬화 discordVisible/initialDocuments 추가. 지원서 강제 Open 제거.
- DiscordViewRoot에 통화·면접 UI 배치. 문서 창과 작업표시줄은 별도 루트 유지.
- SetDiscordVisible(bool) 및 작업표시줄 토글 추가. host·면접 세션 유지.
- [DocumentInitialState.cs](../../Assets/Scripts/Interview/UI/DocumentInitialState.cs): applicationOpen=true, portfolioOpen/scheduleOpen/interviewRecordOpen=false.
- 신규 DTO·Editor 스크립트의 .meta 추가. Assets/Editor 폴더 .meta는 Unity importer 생성 확인 필요.

## CLI 저장·검증 도구
- [WindowInitialStateSetup.cs](../../Assets/Editor/WindowInitialStateSetup.cs): 전역 static ApplyAndSave().
- 메뉴·면접 씬의 누락 설정을 Unity 직렬화로 저장하고 기존 사용자 값 보존. 반복 실행 시 저장 생략.
- [WindowInitialStateValidation.cs](../../Assets/Editor/WindowInitialStateValidation.cs): 전역 static Validate().
- 검증 항목: 최초 숨김, Build 1회, 초기 true의 Opened/Refresh 1회, Close/Open/Toggle, 중복 초기화 무시, 초기 false 무이벤트, 부모 숨김·재표시 상태 유지.
- 저장된 씬 host의 신규 SerializedProperty·명시 저장값·재열기 유지 확인하도록 구현.
- 검증 도구는 사용자 설정 저장·덮어쓰기하지 않음.
- 성공 로그: [WindowInitialStateValidation] PASS. 실패: 예외 및 batch 실패 코드.
- GUI 드래그·영상 표시는 자동 배치 검증 범위 밖.
