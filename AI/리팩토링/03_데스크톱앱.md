# 데스크톱 앱 책임
## 소유자
- DesktopView: 앱 목록의 입력 연결·선택·잠금·작업표시줄 표시 조율 담당함.
- 직렬화 앱 연결: 아이콘·창·활성화 동작의 명시적 관계를 Inspector에 제공함.
- 앱별 처리: 청강코드 연결/시작, 설정 적용, 튜토리얼 표시의 세부 구현 담당함.
- 에디터 authoring: 최초 기본 앱과 창 프레임 구성 담당함. 실행 중 UI 자동 생성과 분리함.

## 계약
- 아이콘 활성화는 등록된 앱 연결을 조회함. 고정 아이콘 비교 분기로 실행 경로를 늘리지 않음.
- 창 초기화·검사·Refresh·Capture도 등록된 창 목록을 사용함.
- 기존 _icons·_code·_settingsWindow·_tutorial·아이콘 참조는 호환 이관의 입력으로 유지함.
- 기존 authored prefab의 새 목록이 비어 있으면 이전 참조로 기본 앱 연결을 구성함. 에디터에서 저장하면 Inspector 목록으로 유지함.
- Build/Bind/Lock/ClearSelection/HasAuthoredUi/RefreshAuthoredContent/CaptureEditorReferences 공개 계약 보존함.
- 청강코드 로딩 완료 후 메뉴의 기존 카메라·씬 전환 흐름으로 연결함.
- 새 앱 등록은 목록과 앱별 동작 연결로 가능해야 함. 중복 아이콘/유효하지 않은 창 연결은 진단함.
- 재활성화·재바인딩 시 이벤트 중복 구독을 만들지 않음.
- 런타임 Bind와 에디터 생성 책임을 분리하되, 현재 창 Build 1회·OnBuilt/BuildInfo 계약을 지킴.

## 검증
- 기존 prefab을 재생성하지 않아도 기본 앱 3개·더블클릭·설정·메뉴 시작이 동작해야 함.
- Inspector 목록 변경이 실제 초기화·실행 대상에 반영되는지 확인함.
- C가 DesktopView/앱 연결/필요 desktop 창 클래스를 수정함.
