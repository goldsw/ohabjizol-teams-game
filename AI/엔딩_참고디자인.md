# 엔딩 참고 디자인

## 범위

- 노멀·배드: 첨부된 4.png·5.png를 기준으로 전체 아트·제목·별점·RESULT 점수판을 배치함.
- 굿: 기존 그림·제목·별점·버튼 배치를 유지하고 하단 오른쪽에 RESULT 점수판만 추가함.
- 프로젝트의 기존 텍스트 없는 엔딩 아트를 재사용함. 첨부 이미지에 인쇄된 점수 0을 그대로 표시하지 않음.
- 대상은 GoodEndingScene·NormalEndingScene·BadEndingScene임. 일반 결과 씬의 달력·배치는 수정하지 않음.

## 데이터

- RESULT: 최종 면접 결과의 ActualSkills를 표시함.
- DIRECTOR: 기획, PROGRAMMER: 프로그래밍, ARTIST: 아트.
- TOTAL SCORE: 위 세 능력치 합계임.
- 별점은 기존 HalfStarUnits 전달·반별 표시를 유지함.
- 결과 데이터 없이 엔딩만 직접 실행하면 점수는 `—`로 표시함.
- 굿 엔딩에서 삭제된 기존 수치 라벨은 선택 항목으로 처리함. 커스텀 제목을 기존 이야기 템플릿으로 덮어쓰지 않음.

## 상태

- 3개 엔딩 씬 적용·저장 완료함. 컴파일 오류·경고 0개임.
- 저장 전후 비교: 굿 엔딩 기존 UI 변경 0건, 일반 결과 씬·프리팹 5개 해시 동일함.
- 노멀·배드: 별 5칸을 항상 표시함. 빈 별은 흰색 테두리, 채워진 별은 흰색으로 표시하고 반별·실제 별점 계산을 유지함.
- 결과 없이 노멀·배드 엔딩을 직접 실행해도 별 5칸을 숨기지 않음.
- 별 표시 후속 작업은 `ApplyStarVisibility()`로 노멀·배드에만 적용함. 별 5등분 배치·불투명도 1·활성 상태를 저장 자산에서 확인함.
- 굿 엔딩: 별 슬롯·빈 별·채움 별·마스크 각 5개 연결 확인함. 씬 파일 해시 동일, 배치·색상·동작 미수정함.
- Play·테스트·커밋 미실행함.
