# 인게임 설정·직접 실행

## 설정 버튼

- 인게임 왼쪽 아래에 설정 버튼을 배치함.
- 기존 SettingsWindow의 사운드·해상도·창 모드 기능을 재사용함. 인게임에서는 최고 기록 초기화·컴퓨터 종료 버튼을 숨기고 다시 시작 버튼을 표시함.
- 다시 시작: 진행 중인 면접 세션을 정리하고 새 회차로 InterviewScene을 재로드함. 최고 기록은 유지함.
- 원본 메뉴 설정 창은 유지함. 인게임 복제본의 종료·기록 초기화 오브젝트는 호환성 참조를 보존한 채 비활성화함.
- 기존 설정 창을 게임 전용 런처에 연결하고 열기·닫기·설정 저장 수명 주기를 연결함.
- 결과 씬의 배치와 달력은 수정하지 않음.

## 직접 실행 오류 원인

- 일반 새 게임 경로는 CampaignRunStore.StartNewRun()을 호출함.
- 인게임 씬 직접 실행은 CampaignInterviewSessionHost.CreateStage()에서 기존 RunId를 그대로 사용함.
- 완료한 스테이지를 다른 점수로 다시 저장하면 StageCompletionService.Validate()가 충돌로 거부함.
- 이 예외를 무시하면 기존 회차 점수를 덮어쓸 수 있으므로 완료 저장 검사는 유지해야 함.

## 직접 실행 보완 — 승인 후 적용

- 파일: `Assets/Scripts/Tutorial/CampaignInterviewSessionHost.cs`의 CreateStage().
- Editor에서 StageSelection.HasValue가 없는 직접 실행만 대상으로 함.
- 회차가 완료됐다면 새 회차를 준비하고 해당 회차의 NextStage를 선택한 뒤 StageManager를 생성함.
- 정상 메뉴 진입과 기존 최고 기록은 유지함. 현재 저장을 직접 초기화하는 작업은 실행하지 않음.
- 미완료 회차의 직접 실행은 해당 회차의 NextStage를 선택함. 완료 저장의 중복·충돌 검사는 그대로 유지함.

## 상태

- 설정 버튼 구현·씬/프리팹 연결 저장 완료함.
- `InGameSettings/SettingsButton`: 왼쪽 아래 기준 (24, 80), 크기 112×48. 별도 Canvas로 기존 배치를 밀지 않음.
- 기존 SettingsWindow를 복제한 독립 프리팹을 공유하며, 열기·닫기·최소화 복원·설정 저장을 연결함.
- 직접 실행 보완 코드 적용 완료함. 컴파일 결과는 `Logs/InGameSettings/direct-entry-compile.json`에 기록함.
- Play·테스트·커밋 미실행함.
