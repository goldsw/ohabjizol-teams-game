# 프로필 내부 사진 축소

## 확정 원인

- 이전 2/3 축소 대상은 중앙 통화 이미지였음. 현재 팀·통화 채널의 원형 프로필 사진에는 적용되지 않았음.
- `InterviewTeamSlotView`의 직렬화된 `_faceScale`·`_faceOffset`이 Bind 시 Transform을 다시 적용하므로 Transform만 수정하면 유지되지 않음.

## 수정 범위

- `Assets/Scripts/Interview/UI/InterviewTeamSlotView.cs`: 프로필 내부 `_portrait`만 기존 배율의 2/3로 축소함.
- 상단 중앙 피벗 `(0.5, 1)`으로 변경하고 기존 이미지 상단 위치를 보존함.
- 축소된 배율·위치를 `_faceScale`·`_faceOffset`에 저장하여 지원자 전환 시 유지함.
- 일회성 직렬화 표시를 사용하여 재적용·새로고침 시 중복 축소를 방지함. 새 프로필 생성에도 같은 기준 적용함.
- 씬 적용: 현재 팀 6개·통화 채널 1개. 원형 마스크·행 크기·이름·파트·중앙 통화 이미지는 변경하지 않음.

## 완료 조건

- 기존 배율 2.2 → 약 1.466667, 피벗 `(0.5, 1)`로 7개 프로필에 저장됨.
- 같은 적용을 반복해도 추가 축소되지 않음.
- 컴파일 결과와 씬 직렬화 상태를 기록함. Play·동작 테스트·커밋은 이번 작업 범위에서 실행하지 않음.

## 적용 결과

- `InterviewTeamSlotView.MigrateProfilePhotoScaleEditor()` 구현·7개 프로필 씬 저장 완료함.
- 씬 재로드 후 7개 모두 배율 `1.466667`·피벗 `(0.5, 1)`·적용 표시 `true` 확인함. 적용 전후 상단 위치 차이 `0`임.
- 최초 Bind 및 새 프로필 생성에도 동일 기준 적용함. 적용 표시가 있으면 추가 축소하지 않음.
- Unity 컴파일 오류 0개·경고 0개. Play 재실행·동작 테스트·커밋 없음.
- 시작 당시 Play를 종료함. 최종 열린 씬은 `MainMenuScene`, 미저장 변경 없음.
- 근거: `Logs/ProfilePortraitShrink/apply.json`, `recompile.json`. 적용 전 씬: `InterviewScene.before.unity`.
