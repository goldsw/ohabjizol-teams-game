# 디코 배경 복구

## 원인

- 2026-10-19 통화방 스킨 적용에서 완성 배경 `Assets/Resources/Interview/Discord_total.png`를 빈 창 프레임인 `DISCORD.aseprite` Sprite로 잘못 교체함.
- Aseprite를 Image에 연결하는 기능은 동작했으나 두 아트의 역할을 잘못 판단함. 원본 이미지 손실은 아님.

## 조치

- Background를 기존 `Discord_total` Sprite로 복원함. Editor 적용기의 기본 매핑도 수정하여 메뉴 재적용 시 재발을 방지함.
- 완성 배경에 이미 있는 통화 도구·서버·채널·LIVE와 중복되는 신규 장식 Graphic 6개를 비활성화함.
- 참가자 `SkinVisual` 3개를 비활성화하고, 참가자 타일의 Sprite·색과 기존 Icon Text를 적용 전 백업 값으로 복원함.
- 참가자 타일 색은 백업을 Unity에서 해석하여 확인함. 원래 tint는 기초색 `(0.19, 0.23, 0.30, 1)`에 참가자별 R 증가값을 적용한 값임.
- 질문 5개, 서류 버튼 2개와 다운로드·채팅 아이콘은 유지함. 기존 위치·계층·이벤트·캐릭터·데이터는 수정하지 않음.
- 파일·객체를 삭제하지 않고 소유한 중복 Graphic만 끔. 공유 G: 원본 변경 없음.

## 결과와 한계

- 최종 컴파일: 오류 0건·경고 0건임.
- InterviewScene 저장 성공, `dirty=false`, Background source가 `Assets/Resources/Interview/Discord_total.png`임을 확인함.
- Background·Canvas 활성, DiscordViewRoot 활성, Canvas는 ScreenSpaceOverlay임을 읽기 전용 조회로 확인함.
- 최종 적용 Image 11곳, 복원 대상 7건, 비활성화 Graphic 9개임.
- PlayMode 실행 및 동작 테스트는 수행하지 않음. EditMode의 Pipeline Game 캡처는 카메라 3D 출력만 반환하여 통화방 UI의 시각 검증 근거로 사용하지 않음.
