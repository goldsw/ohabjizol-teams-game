# 튜토리얼 대사·지원자 연출

## 요청 범위

- 튜토리얼 대사를 한 글자씩 출력함.
- 대사 출력 중 선배의 입 벌림·대기 스프라이트를 반복함. 출력 완료 시 대기 상태로 복귀함.
- 튜토리얼 인물의 표시 이름을 `선배`로 변경함.
- 일반 면접 지원자의 등장·퇴장에 페이드 인·아웃을 적용함.
- 현재 지원자에게 가능한 모든 질문을 완료한 후 합격·불합격 버튼을 표시함.

## 진행 상태

- 튜토리얼: 기본 35글자/초, 한글 글자 단위 출력함. 설명 출력 중 클릭은 문장을 완성하고, 다음 클릭에 단계를 넘김.
- 선배: 기존 character-12의 idle/talk를 0.12초마다 교대함. 대사 완료·숨김·비활성화 시 idle로 복귀함.
- 지원자: 0.25초 페이드 인·아웃 적용함. `InterviewCallView.applicantFadeDuration`에서 조정 가능함.
- 합격: 기존 `InterviewSpeechBubble`에 `감사합니다!`를 1초 표시한 후 지원자·이름·말풍선 함께 페이드아웃함. 완료 후 기존 결정 처리로 다음 지원자 또는 결과로 전환함.
- 불합격: 기존 불합격 포즈 표시 시간 동안 `다음에는 꼭..!` 말풍선을 출력한 후 지원자·말풍선 함께 페이드아웃함.
- 질문: 유효한 질문 문구가 있는 항목을 모두 완료하고 마지막 답변이 끝나야 결정 버튼을 표시함. 지원자 교체 시 다시 숨김.
- UI를 우회한 결정 요청에도 동일 조건을 적용함. 기존 저장 실패 재시도 버튼 경로는 유지함.
- 컴파일 오류 0개·경고 0개 확인함.
- TutorialScene에 선배 이름·idle/talk 참조 저장 완료함.
- Play·테스트·커밋 미실행함.
