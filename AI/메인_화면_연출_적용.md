# 메인 화면 연출 적용 기록

- 기준일: 2026-10-19 KST.
- 설계: [메인 화면 연출 설계](메인_화면_연출_설계.md).
- 상태: FBX·텍스처·런타임 코드·Editor 명령 작성 및 메뉴 적용·대상 씬 저장 완료 확인함.

## 모델·리소스

- 지정 원본 `Assets/Art/Background/Source~/Models/Desk.blend` 사용함. `Desk_v2.blend` 사용 안 함.
- 결과: [Desk.fbx](../Assets/Art/Background/Models/Desk.fbx), 17,599,628바이트, mesh 17개·객체 18개임.
- Blender 5.2.2 LTS 포터블로 별도 변환함. 원본 저장 없이 SHA256 전후 일치 확인함.
- 누락 이미지 5개를 프로젝트 내 원본 경로로 재연결하여 최종 누락 0개임.
- 복구 대상: UUID PNG, Can.png, Gemini 이미지, 갸오.jpg, 갸오방.png임.
- 추출 이미지: `Assets/Art/Background/Textures/Desk/Exported/`임.
- 실제 화면: `Cube.005`의 `Material.006` 면임. 원본 공간에서 폭 약 1.47177m·높이 약 0.70111m임.
- FBX 좌표 변환을 추측하지 않고 Unity가 임포트한 mesh·원본 Camera로 배치 측정함.
- 방 배경은 `Textures/Desk/갸오방.png`, 데스크톱은 `Textures/Misc/Background.png`임.
- 신규 아이콘은 `UI/Lobby/Bin.png`·`Setting.png`임. Discord 표현 유지, Bin은 표시 전용임.
- Documents 경로에 대한 추가 기능·배치는 이번 작업에 포함하지 않음.

## 코드 연결

- [MainMenuController](../Assets/Scripts/Presentation/MainMenuController.cs): 단계·캠페인·입력 잠금·부팅 진행률 관리함.
- [MainMenuCameraController](../Assets/Scripts/Presentation/MainMenuCameraController.cs): 기본 포즈·마우스 미세회전·FOV의 단독 작성자임.
- [ComputerTransitionController](../Assets/Scripts/Presentation/ComputerTransitionController.cs): 실제 화면 사각형으로 중앙 정렬·화면 채움 목표 계산함.
- [SceneLaunchFlow](../Assets/Scripts/Presentation/SceneLaunchFlow.cs): 비동기 로딩·최소 대기·완료 표시 유지·최종 활성화 관리함.
- [LoadingUiPresenter](../Assets/Scripts/Presentation/LoadingUiPresenter.cs): Inspector로 연결한 로딩 UI 표시함.
- [LoadingSceneController](../Assets/Scripts/Presentation/LoadingSceneController.cs): 공통 로딩을 사용하는 레거시 진입 어댑터임.
- 신규 메인 흐름은 LoadingScene으로 먼저 전환하지 않고, 같은 책상·카메라·모니터를 줌 종료까지 유지함.
- 게임 씬은 현행 `InterviewScene`임. StageSelection·CampaignRunStore·최초/재진입 정책 유지함.
- Pending AsyncOperation은 취소하지 않으며, 정렬·줌·활성화 콜백 중복을 차단함.

## 씬 적용

- [MainMenuEnvironmentAuthoring](../Assets/Editor/MainMenuEnvironmentAuthoring.cs)의 명시적인 메뉴 명령으로 적용함.
- Unity 메뉴: **Ohabjizol → Main Menu → Apply Desk Environment**.
- FBX 화면·원본 카메라를 측정하여 설정 asset, 배경, 후광, 카메라 rig, 화면 UI 연결을 저장함.
- 대상: `MainMenuScene`·`LoadingScene`임. 다른 씬은 저장·닫기 대상이 아님.
- 두 대상 씬에 기존 미저장 변경이 있으면 먼저 사용자가 저장한 뒤 다시 실행함.
- 설정 asset: `Assets/Editor/MainMenuEnvironmentSettings.asset`임.
- 생성 후 포즈·화면 크기·시간·아이콘 배치는 Inspector에서 조절 가능함.
- 자동 실행·InitializeOnLoad·Play 진입 없이, 명시적 메뉴 클릭으로만 씬을 변경함.

## 현재 제한과 관측

- 과정 중 Unity CLI 권한 확장 명령이 자동 승인 검토 사용량 한도로 일시 차단됐음. 안전성 판정에 따른 거절은 아니었음.
- 당시 일반 권한 CLI는 Pipeline 인스턴스를 발견하지 못했으며, 사용자가 명시적 메뉴를 실행해 적용함.
- 완료 근거: Editor.log의 `Desk environment applied and both target scenes saved` 기록과 두 대상 씬·설정 asset 저장 확인함.
- MainMenu의 desktop·부팅 진행 UI·transition·loading presenter·환경 root 및 LoadingScene의 화면 frame 참조가 저장됨.
- 이후 승인 검토를 거친 CLI 재연결 성공함. Unity `ready`, `compiling=false`, `domainReloadInProgress=false`, `playMode=stopped` 확인함.
- 최근 로그에 관련 CS 오류·예외가 없었음. PlayMode의 시각·입력·전체 전환 동작은 테스트하지 않음.
- 테스트 추가·실행 및 PlayMode 진입 수행하지 않음.
- Blender 노드 셰이더는 FBX에 그대로 이식되지 않음. 임포트된 Standard 재질은 별도 URP 재질로 연결하며 아티스트 편집 가능함.
