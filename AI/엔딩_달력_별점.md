# 엔딩 별점·결과 달력

## 최신 요청 반영

- 엔딩 달력만 제거함. 달력은 기존 결과 씬에서 표시함.
- 결과 씬 배치·달력·프로필·정확도 바는 수정하지 않음.
- 엔딩의 현재 별점·누적 별점과 배치는 유지함.
- 엔딩 베이크의 달력 복제·표시 경로도 제거하여 다시 생성되지 않게 함.

## 데이터 전달

- 결과 화면이 보유한 동일 InterviewResult를 엔딩 전환 직전에 ResultCarry에 넣음.
- 엔딩 Awake에서 Take하여 한 번만 소비함. 현재 별점은 전달된 HalfStarUnits를 사용함.
- 기존 ResultSceneEntry에서 첫 전달이 이미 소비되므로 엔딩으로 이동할 때 명시적으로 다시 전달함.
- 엔딩 판정과 누적 별점 계산은 기존 CampaignRunStore 경로를 사용함.
- 메인 복귀·새 게임·씬 로드 실패 시 전달 슬롯을 비움.
- 전달 데이터 없이 엔딩 씬을 직접 열면 현재 결과 별점을 숨김.

## 표시

- ResultCalendarView·ResultCalendarCellView는 결과 화면 달력에 유지함.
- 좋음·보통·나쁨·기본 엔딩 씬과 공통 엔딩 프리팹에서 EndingCalendar를 제거함.
- 엔딩 이미지·이야기·별점·버튼의 기존 배치는 유지함.
- 별점은 기존 TenPointStarsView.SetScore(HalfStarUnits)를 사용하여 다섯 별과 반별을 표시함.
- 별점 컴포넌트의 백분율 라벨은 숨기고, 현재 별점·누적 별점 수치를 표시함.

## 상태

- 런타임 별점 전달·결과 화면 달력 코드 유지함.
- 공통 엔딩 프리팹과 기본·Good·Normal·Bad 엔딩 씬 4개 저장 완료함.
- 엔딩 대상 5개에서 달력 없음·별점 참조 유지 확인함.
- 결과 씬 4개와 공통 ResultBoard 프리팹의 작업 전후 SHA256 동일함.
- 달력 제거 대상 4개 에셋의 남은 로컬 fileID 참조 누락 0개 확인함. 기본 엔딩 씬에는 달력이 이미 없어 수정하지 않음.
- Good 엔딩의 기존 OrangeBackground·TotalStars 수동 변경은 보존함.
- 최종 컴파일 오류 0개·경고 0개.
- 기존 결과/엔딩 베이크에서도 엔딩 달력을 다시 생성하지 않음.
- Play·테스트·커밋 미실행함.
