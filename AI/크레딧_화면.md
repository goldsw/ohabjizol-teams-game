# 크레딧 화면

## 동작

- `MainMenuScene` 바탕화면의 **크레딧** 버튼을 한 번 클릭하면 `CreditsScene`으로 이동함.
- 기존 아이콘 열의 높이를 고려해 옆 열 상단에 버튼을 배치함.
- 크레딧은 검은 배경·흰 글씨이며, 첫 표시 프레임 이후부터 3초 동안 페이드인함.
- `Time.realtimeSinceStartupAsDouble`을 사용하여 시간 배율의 영향을 받지 않음.
- 페이드인이 끝나면 **메인 화면으로 돌아가기** 버튼을 사용할 수 있음.
- 복귀 시 시작 타이틀을 억제하고 `MainMenuScene`으로 이동함.
- 오른쪽 `EmptyResultArea`는 자식·이미지·텍스트가 없는 빈 영역임. 플레이 결과 데이터 연결 없음.

## 작성 방식

- Graphify의 기존 `graphify-out/graph.json`에서 메뉴·아이콘·UI 폰트 구조를 참고한 뒤 관련 소스 확인함.
- 기존 바탕화면 아이콘의 프레임·배치 크기를 재사용함. 크레딧 아이콘은 창 앱 목록 대신 씬 이동 버튼으로 연결함.
- 공용 `PFStardustBold` 폰트 사용함.
- `CreditsScene`을 빌드 목록에 활성 등록함.
- 현재 열린 메인 메뉴의 기존 편집 내용을 저장·백업한 뒤 버튼만 증분 추가함.
- 기존 `ProjectSettings.asset`의 파일 해시가 적용 전후 동일함.
- 기존 크레딧 씬·버튼이 있을 때 작성 도구를 재실행하면 해당 수동 배치를 보존함.

## 확인 기록

- Unity 컴파일: 오류 0건·경고 0건.
- 편집 모드 미리보기에서 글자·배치·복귀 버튼 확인함.
- 씬 참조·3초 설정·입력 모듈 액션·빌드 등록·버튼 연결 확인함.
- 빈 결과물 영역: 자식 0개·Graphic 0개 확인함.
- Play·테스트·빌드·커밋 미실행함.
- 백업·컴파일 결과·작성 상태·미리보기는 `Logs/Credits/`에 저장함.

## Heading 반복 이동

- [HeadingYLoop.cs](../Assets/Scripts/Presentation/HeadingYLoop.cs)를 팀 소개 Heading 5개에 부착함. 자식 Name은 함께 이동함.
- `Min Y`·`Max Y`: 활성화 시 현재 Y 위치를 기준으로 더하는 상대 오프셋임. 스크립트 초기값은 -10/+10이며, 현재 씬의 사용자 설정 -20/+20을 유지함. Heading 위치를 옮겨도 새 위치를 기준으로 움직임.
- `Start Delay`: 첫 표시 프레임 이후 이동 시작 지연 시간임. 현재 씬의 사용자 설정 3.0~4.6초를 유지함.
- `Move Speed`: sin 목표의 최대 속도이며 기본 8 UI픽셀/초임. 누적 위상을 `속도 / 반폭 × 경과 시간`만큼 증가시킴.
- `Position Lerp`: 현재 위치가 sin 목표 위치를 따라가는 보간값이며 기본 0.12임.
- `Range Lerp`: min/max 폭 변경을 부드럽게 따라가는 보간값이며 기본 0.08임. 두 보간값 모두 60FPS 기준으로 해석하고 프레임 시간에 맞춰 보정함.
- 목표 위치는 `기준 Y + 중심 오프셋 + 반폭 × sin(위상)`으로 계산함. 중앙에서 빠르고 끝에서 느려지며 방향이 바뀜.
- 시작 지연 동안 현재 위치를 유지하고 첫 이동은 max 방향으로 시작함. Team 클릭으로 속도·범위가 바뀌어도 위상을 다시 시작하지 않으며 시간 배율의 영향을 받지 않음.
- 비활성화 시 원래 Y 위치를 복원하여 재활성화할 때 기준점이 누적 이동하지 않음.
- 사용자 작성 Heading/Name 계층과 위치를 유지한 채 컴포넌트만 추가함.
- 컴파일·작성 설정·씬 백업: `Logs/CreditsHeadingMotion/`. Play·테스트 미실행함.

## Team 클릭으로 움직임 강화

- `CreditsCanvas/HeadingMotionManager`의 [CreditsHeadingMotionManager.cs](../Assets/Scripts/Presentation/CreditsHeadingMotionManager.cs)가 Heading 5개를 관리함.
- `Foreground/Team` 텍스트에 Button을 연결함. 외형은 유지하며 클릭을 받을 수 있도록 설정함.
- 클릭마다 min 오프셋 -20, max 오프셋 +20; 범위 한계는 -100/+100임.
- 현재 씬의 범위 변화: ±20 → ±40 → ±60 → ±80 → ±100.
- 속도는 클릭마다 20 UI픽셀/초 증가하며 기본 상한 100임. 기본값 8 → 28 → 48 → 68 → 88 → 100.
- `Range Step`, `Range Limit`, `Speed Step`, `Speed Limit`은 매니저 인스펙터에서 조절 가능함.
- 진행 방향·기준 위치·시작 지연을 유지하며 속도와 경계가 함께 바뀜. 클릭 시 위치를 순간 이동하거나 루프를 재시작하지 않음.
- 컴파일 오류·경고 0건, 매니저·Heading 5개·Team 클릭 참조 확인함. Play·테스트 미실행함.
- 씬 백업·작성 기록은 `Logs/CreditsHeadingBoost/`에 저장함.
- 등속·경계 반전 방식으로 교체한 컴파일 결과·씬 설정·이전 코드 백업은 `Logs/CreditsHeadingVelocity/`에 저장함. Play·테스트 미실행함.
- 이후 누적 위상 sin 목표와 위치·폭 Lerp 방식으로 변경함. 기존 속도·범위·시작 지연과 Team 매니저 설정은 유지함. 컴파일 오류·경고 0건; 기록은 `Logs/CreditsHeadingPhase/`에 저장함. Play·테스트 미실행함.

## Title 크기 반복

- `Foreground/Title`에 [TitleScaleLoop.cs](../Assets/Scripts/Presentation/TitleScaleLoop.cs) 부착함.
- 활성화 당시 크기를 기준으로 0.9~1.2배 사이를 sin 곡선으로 순환함. 현재 크기에서 시작해 커지는 방향으로 진행하며 비활성화 시 기준 크기를 복원함.
- `Min Scale`, `Max Scale`, `Cycle Duration` 조절 가능함. 기본 주기는 4초이며 시간 배율의 영향을 받지 않음.
- Team 클릭에 따른 Heading 움직임과 독립적으로 동작함.
- 컴파일 오류·경고 0건. 씬 백업·작성 기록: `Logs/CreditsTitleScale/`. Play·테스트 미실행함.
