# 튜토리얼 문서 창 닫기

- 문서함 닫기 단계에서 문서함·지원서·포트폴리오 창을 모두 닫도록 안내함.
- 문서함 X 버튼을 먼저 강조하고, 닫으면 남아 있는 문서 창의 X 버튼을 강조함.
- 문서 창 하나를 닫으면 강조 대상을 남아 있는 창으로 갱신함.
- 세 창이 실제로 모두 닫혀야 질문 단계로 이동함. 최소화는 닫기로 처리하지 않음.
- 최소화된 창은 기존 창 복원 동작으로 다시 표시하여 X 버튼을 누를 수 있게 함.
- 이미 닫힌 창은 완료 상태로 처리함. 닫기 버튼은 기존 WindowToolbar 참조를 재사용함.
- 지원서·포트폴리오와 문서함의 배치·프리팹을 다시 생성하지 않음.
