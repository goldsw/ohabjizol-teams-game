# 허위 지원자·포트폴리오 검증 및 별 기준 엔딩

## 검증 결과

- EditMode 테스트 46개 통과: 기존 허위 판정·정확도 34개, 새 별 기준 엔딩 경계 12개.
- 일정 감점 추가 후 실제 계산 소스를 독립 .NET 프로젝트로 컴파일하여 21,955개 검사 통과함: 0~100점·0~6명·0~30일 조합, 비작업일 제외, 실제 스탯 점수 연결, 소수점 보존, 감점 후 엔딩 경계 포함함.
- 288개 메모리 세션 검증 통과: 직군 3종 × 실제 포트폴리오 등급 3종 × 허위 확률 0/1 × 시드 16개.
- 허위 96건·정상 192건에서 보이는 카드 등급·질문 답변·최종 허위 표시 일치함.
- InterviewScene의 허위 확률 0.5 및 실제 카탈로그 연결 확인함.
- 기획·프로그래밍·그래픽 각 Good/Normal/Bad 9개 원화·카드·메모 참조 일치 확인함.
- 게임 UI를 조작하는 전체 Play 검증은 하지 않음. 기존 씬·캠페인 저장 데이터는 변경하지 않음.

## 허위 판정 기준

- 세션 생성 시 `FakePortfolioQuality`를 한 번 결정하고 유지함.
- 허위 여부는 `FakePortfolioQuality.HasValue` 기준임. `ApplicantKind`의 이전 분류값만으로 판단하지 않음.
- 포트폴리오 문서는 `TruePortfolioQuality` 등급 카드로 표시함.
- 답변은 `FakePortfolioQuality ?? TruePortfolioQuality` 등급 문구에서 선택함.
- 허위 등급은 실제 등급보다 반드시 낮음. 실제 Bad 포트폴리오는 더 낮은 등급이 없으므로 허위로 생성되지 않음.
- 따라서 같은 등급의 문서·설명은 정상이며, Good 문서/Normal·Bad 설명 또는 Normal 문서/Bad 설명은 허위 사례임.
- 허위 확률 0.5는 허위 생성이 가능한 Good/Normal 지원자에 적용됨. 모든 지원자 중 정확히 절반을 강제하는 규칙은 아님.

## 정확도·별 계산

- 합격한 팀의 실제 능력치 합계를 사용함. 지원서에 표시된 예상 능력치 합계와는 다를 수 있음.
- 요구량이 양수인 직군마다 `오차율 = min(abs(실제 합계 - 요구량) / 요구량, 1)` 계산함.
- `감점 전 정확도 = 100 × (1 - 직군별 오차율 평균)`임.
- 지원자별 일정 감점 = `(감점 전 정확도 / 6) × (빠진 작업일 수 / 30)`임. 같은 날 여러 명이 쉬면 인원별로 합산하며, 비작업일 휴무는 제외함.
- `최종 정확도 = floor(max(0, 감점 전 정확도 - 지원자별 일정 감점 합계))`, 결과 범위 0~100임. 중간 반올림 없이 최종값만 내림함.
- 요구량 초과와 부족을 모두 오차로 계산함. 부동소수 정수 경계 오차는 코드에서 보정함.
- `반별 개수 = 정확도 / 10`의 정수 몫, `별 개수 = 반별 개수 / 2`임.
- 예: 49% → 2개, 50% → 2.5개, 69% → 3개, 70% → 3.5개, 100% → 5개.

## 변경한 엔딩 기준

- Good: 표시 별 3.5개 이상.
- Normal: 표시 별 2.5개 이상, 3.5개 미만.
- Bad: 표시 별 2.5개 미만. 현재 반별 단위에서는 2개 이하임.
- 현재 활성 스테이지는 입학 게임잼 하나이므로 정확도 70% 이상 Good, 50~69% Normal, 0~49% Bad임.
- 여러 스테이지를 활성화하면 활성 스테이지의 표시 별 평균을 5개 기준으로 비교함. 미완료 스테이지는 0개로 취급함.
- 최종 이동은 완료한 캠페인의 `run.Ending` → `EndingSceneRoute.For`로 결정함.
- 개별 Good/Normal/Bad 엔딩 씬의 그림 종류 고정 설정은 유지함.
- 네 엔딩 씬의 실제 로드 임계값 Good 3.5·Normal 2.5 확인함.

## 현재 점수 반영 범위

- 일정 충돌 감점은 최종 정확도·별점·클리어·엔딩에 반영함. 실제 능력치 합계와 별도 충족률은 유지함.
- 허위 인원수 자체는 정확도와 별점에서 직접 감점하지 않음.
- 허위 인원수는 별도 프로토타입 S/A 등급에 영향을 주지만, 최종 엔딩은 이 등급을 사용하지 않음.
- 실제 능력치가 예상 능력치와 다르면 실제 합계에 따른 정확도 차이는 생길 수 있음.
- 일정 감점 추가 검증: Unity Editor 미연결로 EditMode 재실행 불가. 독립 .NET 검증 결과는 `Logs/SchedulePenaltyVerification/`에 기록함.
