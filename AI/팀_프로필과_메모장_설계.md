- SelectedTeamDisplaySnapshot.Members 순서·CharacterId 사용함. 이름·role 매칭 금지함.
- TryGet(CharacterId, out visual) 성공 및 visual.Idle != null일 때만 Idle 표시함.
- Bind마다 sprite 초기화함. 빈 자리·누락/중복 ID는 authored placeholder 표시함.
- 슬롯6개 사전 제작함. 초과는 명확 진단, 런타임 생성 금지함.
- BindTeam은 얼굴만 갱신함. Slot 문구·현재팀 능력치 계산/표시는 기존 API 담당임.
- _slotLabels·_currentLabel·_requiredLabel, SelectedTeamDisplaySnapshot.DisplayedSum 및 Current/Required 갱신 경로 보존 필수임.

## notepad + runtime: 시작된 B 계약
- B 독점 신규 파일: `Assets/Scripts/Interview/Runtime/StageNotepad.cs`, UI의 InterviewNotepadWindow.cs·InterviewNotepadLauncher.cs임.
- StageNotepad: `Content { get; }`, `event Action<string> Changed`, `SetContent`, `Clear`임.
- Window : InfoWindow: `HasAuthoredInput`, `Bind(StageNotepad)`, `Unbind()`, Editor `ConfigureEditor(InputField)`; BuildInfo는 비어 있음.
- Launcher: `ConfigureEditor(window, button, surface)`, Start의 ApplyInitialState(false), 최소화 회색임. 기존 teamlauncher 패턴 재사용함.
- B는 기존 파일 수정 없음. 기존 InterviewTeamLauncher 일반화 계획은 폐기함.
- 부모가 authored 창 하나·multiline InputField·본문/placeholder Text·FixedApps/NotepadButton 상시 아이콘 제작함.
- 한국어 폰트는 DocumentLibrary Text.font 등 기존 persistent Noto assetref 확보함. 실패 시 preflight 명확 오류로 중단함.
- UI 생성은 Editor 전용임. OS/dynamic font fallback·추가검색·BuildInfo/Refresh의 생성 금지함.
- 창 열림→Minimize, 닫힘/최소화→Restore, X→Close임. 창 비활성화로 본문·런처 제거 금지함.
- 입력 변경은 즉시 SetContent, 복원은 SetTextWithoutNotify 사용함. OnDisable의 낡은 입력 역복사·Refresh 초기화 금지함.
- Bind/Unbind는 교체 시 이벤트 중복·누수 방지함. 닫힌 상태도 Content 보존, 재표시 시 최신 Content 복원함.
- StageManager가 Notes 인스턴스 하나를 소유함. Runtime.Create가 창에 바인딩하고 Dispose에서 해제함.
- 저장 성공 → Result 대입 → Notes.Clear → StateChanged 순서임. Clear는 빈 문자열 중복 알림을 보내지 않음.
- CompletionPending/CompletionFailed에서는 보존함. 저장 예외와 Notes 알림 예외를 같은 catch로 처리하지 않음.
- 창·화면 비활성화에서는 Notes를 초기화하거나 창의 바인딩을 해제하지 않음.
- 창 닫기·최소화·지원자전환·화면 비활성화는 Clear 조건 아님. 앱 재실행 복원은 범위 밖임.

## profiles API·남은 통합 경계
- P: `InterviewTeamSlotView.BindPortrait(SelectedApplicantDisplay member, ApplicantVisualCatalog catalog)`; null은 빈 자리임.
- P: `InterviewTeamWindow.BindTeam(SelectedTeamDisplaySnapshot snapshot)`; 직렬화 catalog·6개 slot 소비, 능력치·문구 변경 없음.
- P: Editor `ConfigureProfilesEditor(InterviewTeamSlotView[] slots, ApplicantVisualCatalog catalog)`, `InterviewScreen.BakeTeamProfilesEditor()` 제공함.
- P 쓰기: UI의 InterviewTeamWindow.cs·InterviewScreen.TeamWindow.cs·신규 InterviewTeamSlotView.cs만 허용함.
- 부모 신규 partial: UI의 InterviewScreen.Notepad.cs·InterviewScreen.NotepadAuthoring.cs임.
- 부모 runtime: StageNotepad 소유·Bind/Unbind, StageManager.StateChanged→Result 확정 Clear, 기존 snapshot→BindTeam 연결함.
- Runtime의 RenderSummary가 기존 요약 표시 후 Session.ReadSelectedTeam()의 표시용 snapshot을 TeamWindow.BindTeam에 전달함. 실제 스탯 데이터는 뷰로 전달하지 않음.
- 부모 기존 파일: UI의 InterviewScreen.Authoring.cs·InterviewScreen.DocumentAuthoring.cs, `Assets/Editor/InterviewRefresh/TeamWindowBake.cs`임.
- 부모 Apply: Noto/input preflight→팀/메모장 bake→모든 창 EnsureControlsEditor→참조 저장함.
- HasAuthoredUi 조기 return 경로도 새 authoring 호출 포함함. 기존 사용자 배치는 보존함.
- FixedApps는 모두 추가한 뒤 preferredWidth 재산정함. DocumentAuthoring 고정344의 덮어쓰기 방지함.
- scene/prefab/asset/.meta·기존 runtime 호출부·이 문서는 부모 단독 소유함. workers의 씬 저장·bake 실행 금지함.
