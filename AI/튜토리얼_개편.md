- 기준 원문: `C:/Users/eeseo/Downloads/시나리오.txt`.
- 작업 시점 원문: `Logs/TutorialRevision/scenario-source.txt`.
- 대사·단계 정의: `Assets/Scripts/Tutorial/TutorialScenario.cs`, 총 67단계.
- 지원자 화면 소개·인사·응답 설명 단계는 실제 `PortraitRect` 위치를 따라 강조함.
- 안내 흐름: 선배 등장 → 화면·현재 팀·김씨 → 지원서·포트폴리오 다운로드 → 포트폴리오 질문 → 문서함 파일 대조 → 일정 질문·프로젝트 일정 대조 → 실제 합격 → 팀 능력치·요구량 설명 → 메모장 → 선배 종료 대사.
- 원문에 생략된 문서 파일 열기·중간 창 닫기는 해당 버튼을 직접 누르는 단계로 보완함.
- 설명 단계: 아무 곳이나 클릭하여 진행함. 마지막 완료 단계는 키보드·게임패드 입력도 지원함.
- 조작 단계: 해당 버튼/문서 행만 입력 허용함. 질문 응답·다운로드·합격 연출은 실제 완료까지 대기함.
- 응답·합격 대기 중 화면 강조는 유지하고 추가 입력은 차단함.
- 질문·합격 대기 시 해당 버튼의 강조 위치를 유지함.
- 기존 타자 효과, 선배 Idle/Talk 전환, 어두운 판·투명 강조 구역을 유지함.
- 튜토리얼 지원자는 기존 시드로 역할·표시 능력치를 생성하되 정직한 보통 포트폴리오 사례로 구성함.
- 원본 지원자 프로필·일반 게임의 허위 확률은 변경하지 않음.
- 실제 합격은 튜토리얼 세션에서만 처리함. 캠페인 기록 저장 콜백은 비어 있으며 결과 씬으로 이동하지 않음.
- `InterviewExit`도 세션의 `HandoffSceneName` 허용 여부를 확인한 뒤 일반 결과 경로를 실행함.
- 완료 입력 후 튜토리얼 완료 기록을 남기고 메인 화면으로 복귀함.
