# 팀 프로필·창 컨트롤·메모장 적용

- 후속 정정: Prefab 원본 Slot Text의 그룹 이동은 실제로 적용되지 않았음. [후속 수정안·적용 결과](통화_UI_한글입력_엔딩_설계.md)에서 새 Caption 연결·원본 비활성·행 레이아웃으로 복구함. 아래 초기 그룹화 설명보다 후속 기록을 우선함.

## 요청 범위

- 현재 팀의 각 자리: 프로필과 빈 자리/팀원 정보를 같은 그룹으로 구성함.
- 선택된 팀원의 프로필을 왼쪽에 표시하고 profile Sprite 모양의 Unity UI 스텐실 Mask 내부에만 렌더링함.
- 창 툴바 최소화·닫기 버튼에 `-`, `X` 기호를 표시함.
- 화면 왼쪽 하단 별 표시를 제거함. 현재 팀 창의 능력치 정보는 유지함.
- 작업표시줄에 상시 아이콘이 있는 fixed 메모장 창을 추가함.
- 메모는 최소화·닫기·지원자 전환 후에도 유지하고 스테이지 종료 시 초기화함.

## 변경 전 상태

- Unity 6000.3.15f1, Editor 실행 중·Play 정지 상태 확인함.
- InterviewScene의 미저장 편집은 `Logs/TeamProfileNotepad/Before`에 씬 사본으로 보관함. 원본 씬은 닫거나 교체하지 않음.
- 직전 다운로드 항목 분리·Check 연결은 [이전 적용 기록](다운로드_항목_분리_적용.md)을 참조함.
- 좌하단 대상은 `InterviewScreen/InterviewAuthoredUi/DiscordViewRoot/ApplicantStats`의 ApplicantStatsView 1개임.
- 현재 팀 TeamSummary의 기존 자식은 Slot0~Slot5, Current, Required임. 슬롯 Text 참조와 현재·요구 능력치는 보존 대상임.
- StageCalendar.Close와 RadialQuestionWindow.Close/Minimize의 Text Font가 null임. 다른 창에도 기호 라벨 영역이 24×24여서 Font 연결과 함께 Overflow를 보정할 필요 있음.
- 근거: `Logs/TeamProfileNotepad/controls-before.json`, `team-before.json`, `fresh-backup.json`임.

## 구현 구조

- [구조 계약](팀_프로필과_메모장_설계.md)에 책임과 API를 기록함.
- `InterviewRuntime.RenderSummary → Session.ReadSelectedTeam → InterviewTeamWindow.BindTeam → InterviewTeamSlotView.BindPortrait`로 팀원 얼굴을 갱신함.
- 기존 Slot0~Slot5 Text를 SlotGroup0~SlotGroup5에 그대로 넣고 왼쪽 Mask·Portrait·빈 자리 Placeholder를 추가함. Current·Required 참조는 유지함.
- `profile.aseprite`의 native 하위 Sprite `profile`을 Mask에 연결함. Portrait는 CharacterId에 맞는 ApplicantVisualCatalog.Idle을 사용함.
- Mask 6개는 showMaskGraphic=false, Portrait.maskable=true와 기본 UI 재질을 사용함. Face Scale·Face Offset은 Inspector에서 조정 가능함.
- `WindowToolbar.EnsureControlsEditor`가 기존 및 신규 창의 `-`, `X`를 보정함. 폰트는 저장 가능한 LegacyRuntime, 라벨 40×40·Overflow를 사용함.
- `StageManager.Notes`가 메모를 소유하고 창은 InputField와 바인딩함. 저장 성공 후 Result 확정 시 Clear하며 실패·창 닫기·최소화·지원자 전환·화면 비활성화에서는 유지함.
- 메모장은 NotoSansKR 다중줄 입력을 사용하며 작업표시줄 FixedApps/NotepadButton으로 다시 열 수 있음. 고정 앱 전체 폭은 자식 기준으로 계산함.

## 씬 적용 기록

- `Ohabjizol → Interview → Apply Team Profiles and Notepad` 메뉴로 현재 열린 씬에 적용함. 메뉴는 씬을 저장하지 않음.
- 씬 창 5개, 프로필 그룹·스텐실 Mask 6개, 고정 메모장 1개 연결 확인함. 최초 메모장은 닫힌 상태임.
- PDF Viewer prefab의 툴바도 보정·저장함. 현재 씬과 prefab 원본 사본은 Logs/TeamProfileNotepad/Before에 보관함.
- 좌하단 ApplicantStats는 참조를 유지한 채 비활성화함. 현재 팀 수치와 Discord_total.png 배경을 유지함.
- 필수 에셋 검사 첫 시도는 profile.png가 Texture2D여서 변경 전 중단됨. native Sprite 연결로 보정 후 적용 완료함.
- `recompile-final.json`: 오류 0건·경고 0건임. `apply.json`, `bindings.json`에 정적 연결 확인 결과 기록함.
- 저장 전 검사에서 `_stageLabel` 누락을 발견함. 다른 필수 UI는 정상이며 기존 보조 라벨 누락 때문에 화면 전체 초기화가 차단되는 상태였음.
- 사용자 작업표시줄 배치를 보존하기 위해 StageLabel 필수 검사 제외·Render null guard로 보정함. StageDefinition·진행 정보·상단 Title의 스테이지 표시는 유지함. 기본 authoring의 Stage 생성도 유지함.
- InterviewScene만 저장 완료함. `save.json`: saved=true, authored=true, dirty=false, playing=false임.

## 확인 범위

- 컴파일·현재 씬의 정적 참조를 확인함. 실제 입력·얼굴 표시·창 클릭의 PlayMode 실측은 수행하지 않음.
- 사용자 요청 없는 PlayMode·테스트·커밋은 수행하지 않음.
