# 제작 진행 중간 씬

## 동작

- 최종 모집 인원이 정확히 6명일 때 `면접 → ProductionProgressScene → 원래 판정된 결과 씬` 순서로 이동함.
- 6명 미만으로 지원자가 소진된 결과는 기존 결과 씬으로 바로 이동함.
- 좌상단 `Calendar/DayNumber`: 1일부터 30일까지 0.3초 간격으로 변경함. 30일부터 날짜를 빨간색으로 표시함.
- 중앙 문구 순서: 컨셉 기획중 → 시스템 기획서 작성 중 → 작업 지시 중 → 컨셉 아트 그리는중 → 프로그래밍 중 → 버그 픽스중 → 회의 → 스크래치 제작 중 → 프로토타입 제작중.
- 30일 진행은 총 9초이며 작업 문구는 각각 약 1초씩 표시함. 마지막 `발표일!!!`은 1.2초 유지함.
- 모든 문구의 끝 점을 `.` → `..` → `...` 순서로 0.3초마다 반복함.
- 시간 배율과 관계없이 진행함. 날짜 간격·점 간격·발표 문구 유지 시간은 Inspector에서 조정 가능함.
- 중간 씬은 ResultCarry의 결과를 소비하지 않음. 기존 결과 씬에서 달력·별점·지원자 정보를 그대로 수신함.
- 기존 결과 씬·프리팹의 배치는 편집하지 않음.

- 컴파일 오류 0개·경고 0개 확인함.
