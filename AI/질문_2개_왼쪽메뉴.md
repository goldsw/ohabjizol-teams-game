# 질문 2개·지원자 왼쪽 메뉴

- 포트폴리오 프로젝트·일정 질문만 유지함. 기존 빈 질문 3개는 카탈로그와 활성 메뉴에서 제외함.
- 질문 버튼 클릭 시 지원자 왼쪽에 2개 버튼을 세로로 표시함. 원형 배치·회전 계산은 제거함.
- 지원자 이미지의 위치·크기·종횡비에 따라 메뉴 위치를 맞춤. 기본 버튼 300×56, 세로 간격 12, 지원자와 간격 24임.
- 기존 질문 런처·열기/닫기·튜토리얼 질문 0/1 흐름 유지함.
- 2개 답변 완료 후 합격·불합격 버튼이 표시됨.
- 질문 클릭 즉시 같은 스프라이트의 회색 반투명(알파 0.5) UsedOverlay를 위에 표시함. 새 지원자·질문 취소 시 기존 사용 상태에 맞춰 해제함.
- 덮개는 Raycast를 받지 않음. 다른 질문의 일시적 입력 차단에는 덮개를 표시하지 않음.
- 기존 추가 질문 오브젝트는 비활성 상태로 보존하고 활성 배열은 2개로 축소함.
- 기존 역할별 질문·응답 0/1의 내용을 보존함. 팀 슬롯·별점 개수는 변경하지 않음.
- 작업표시줄·면접관 타일·결과 씬 배치를 변경하지 않음.

## 파일·적용

- [질문 수·정의](../Assets/Scripts/Interview/Data/InterviewQuestionCatalog.cs): `QuestionCount = 2`.
- [배치](../Assets/Scripts/Interview/UI/RadialQuestionView.cs): 기존 스크립트 식별자는 호환성을 위해 유지함.
- [명시적 에셋 적용](../Assets/Editor/InterviewRefresh/TwoQuestionMenuBake.cs): `TwoQuestionMenuBake.Apply()`.
- 기록·백업: `Logs/TwoQuestionMenu/`.

## 상태

- 공통 프리팹과 Interview·Tutorial 씬의 질문 메뉴·참조 저장 완료함.
- 역할별 질문 2개, authored 질문 총 6개·응답 18개로 정리함.
- 컴파일 오류 0개·경고 0개. 기록: `compile.json`, `apply-state.txt`, `authored-state.txt`.
- 질문 사용 덮개도 공통 프리팹·두 씬에 저장함. 기록: `Logs/QuestionUsedOverlay/`.
- Play·테스트·커밋 미실행함.
