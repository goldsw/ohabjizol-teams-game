# 시작 로고 연출

## 순서·시간

- 실행 세션 최초 메인 진입 시 1회 표시함. 메인으로 돌아올 때 반복하지 않음.
- 검은색 배경의 팀 로고 → 흰색 배경의 게임 타이틀 → 기존 시작 입력 화면. 후속 요청에 따라 Made With Unity 화면을 제외함.
- 각 로고 화면: 페이드 인 0.3초 + 유지 0.9초 + 페이드 아웃 0.3초, 총 1.5초임.
- 로고 전체 약 3초 후 `화면 터치하여 시작` 문구가 점멸함. 초기 로딩 시간은 재생 시간에 포함하지 않음.
- 로고 중 입력은 시작 화면을 넘기지 않음. 종료 직후 입력도 한 프레임 추가 차단함.
- 첫 렌더 완료 후 초기 delta를 제외하고 페이지별 unscaledDeltaTime을 누적함. 다음 페이지에 초과 시간을 이월하지 않고, 긴 프레임은 0.1초까지만 반영함.

## 리소스·구조

- 기존 `Assets/Art/Logo/TeamLogo.png`, `GameTitle.png`를 RawImage에 연결함.
- 로고 비율 유지, 기존 PNG와 임포트 설정을 변경하지 않음.
- 메인 씬에 별도 Canvas·입력 차단막·2개 페이지를 편집 단계에서 저장함.
- Unity 기본 스플래시도 비활성 상태를 유지함.
- 편집기의 스플래시 setter가 파일에 반영되지 않아 `m_ShowUnitySplashScreen` 한 항목만 0으로 저장함. 나머지 설정·줄바꿈·UTF-8 BOM은 보존함.
- 백업·적용 기록: `Logs/StartupLogos/`.

## 상태

- 타이머 수정 전후 실행 기록: [실행 진단](시작_로고_실행진단.md).
- 컴파일 오류·경고 0개임. 로고 PNG·메타 파일 4개의 해시 동일함.
- 최종 두 페이지 구성으로 Play 재검증함. 팀·게임 로고의 실제 렌더·페이드·완료 및 시작 문구 캡처를 확보함.
- 진단 코드와 임시 백그라운드 실행 설정은 제거함. 빌드·단위 테스트 미실행함.

## 앞 구간 미표시 진단

- 사용자 확인 대상: Unity·팀 로고 구간임. 게임 타이틀 뒤의 터치 문구 문제와 구분함.
- 저장된 3개 페이지 순서·참조·화면 크기·활성 상태·1.5초/0.3초 설정 정상임.
- 수정 전: Awake 시각 0초 → 첫 Update 3.368615초에 index 2로 이동함. 앞 두 페이지 렌더 0회로 생략 원인을 확정함.
- 수정 후: 페이지별 타이머와 최초 렌더 대기를 적용하여 순차 표시를 확인함. 진단용 코드는 제거함.
- 기존 비활성 `MainMenuTitleOverlay`도 활성화하여 최종 시작 문구를 연결함.
